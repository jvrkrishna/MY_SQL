# MySQL – Introduction & Basic Concepts

## 1. What is Data?

**Data** means raw facts and information that can be stored and processed by a computer.

### Examples:

* Student name: Ravi
* Age: 20
* Marks: 85
* Phone number: 9876543210
* Product price: ₹500

👉 **Simple definition:**
**Data is a collection of raw facts and figures.**

---

# 2. What is a Database?

A **Database** is a systematic and organized collection of data.

It is used to **store, manage, access, modify, and delete data** according to our requirements.

### Example:

A college database may contain:

| Student ID | Name  | Age | Marks |
| ---------- | ----- | --: | ----: |
| 101        | Ravi  |  20 |    85 |
| 102        | Sita  |  19 |    90 |
| 103        | Kumar |  21 |    78 |

Here, the student information is stored in a **database**.

### Simple definition:

> **Database = An organized collection of data.**

---

# 3. Why Do We Need a Database?

Suppose a college has 5,000 students.

If we store all student information in separate files, it becomes difficult to:

* Find student information
* Update student details
* Delete old information
* Avoid duplicate data
* Share data
* Protect data

A database helps us manage all this information efficiently.

---

# 4. Types of Databases

Some common types of databases are:

### 1. Relational Database

Data is stored in the form of **tables** consisting of rows and columns.

**Examples:** MySQL, Oracle, SQL Server

### 2. NoSQL Database

NoSQL databases are generally used for storing data that does not follow the traditional table-based relational structure.

**Examples:** MongoDB, Cassandra

### 3. Centralized Database

The complete database is stored and managed at a **central location**.

### 4. Cloud Database

The database is hosted on **cloud platforms** and can be accessed through a network or the internet.

---

# 5. Advantages of a Database

Databases provide many advantages:

### 1. Reduces Data Redundancy

**Redundancy** means unnecessary duplication of data.

A database helps reduce duplicate data.

### 2. Backup and Recovery

Database systems provide methods to **backup data and recover it** when data is lost or damaged.

### 3. Efficient Data Processing

Databases provide efficient ways to **search, retrieve, and process data** using queries.

### 4. Security

Databases can protect data by using:

* User accounts
* Passwords
* Permissions
* Access control

### 5. Data Sharing

Multiple authorized users or applications can access and use the same database.

### 6. Data Abstraction

Users do not need to know all the internal details of how data is stored.

They can work with the data using simple commands and interfaces.

---

# 6. What is DBMS?

**DBMS** stands for:

> **Database Management System**

A DBMS is **software used to create, store, manage, and control databases**.

### Examples of DBMS software:

* MySQL
* Oracle Database
* Microsoft SQL Server
* PostgreSQL
* Microsoft Access

### A DBMS allows us to:

* Create databases
* Store data
* Read data
* Update data
* Delete data
* Control access to data
* Backup and recover data

### Simple definition:

> **DBMS is software used to manage databases.**

---

# 7. What is RDBMS?

**RDBMS** stands for:

> **Relational Database Management System**

An RDBMS is a type of DBMS that manages data using the **relational model**, mainly through tables.

### Data is generally organized as:

**Database → Tables → Rows + Columns**

Example:

**Student Table**

|  ID | Name | Age |
| --: | ---- | --: |
| 101 | Ravi |  20 |
| 102 | Sita |  19 |

Here:

* **Table** → Student
* **Rows** → Individual student records
* **Columns** → ID, Name, Age

### Simple definition:

> **RDBMS is a DBMS that manages data in the form of related tables.**

---

# 8. DBMS vs RDBMS

| DBMS                                                    | RDBMS                                           |
| ------------------------------------------------------- | ----------------------------------------------- |
| Database Management System                              | Relational Database Management System           |
| Manages databases                                       | Manages relational databases                    |
| May use different data models                           | Uses the relational model                       |
| Relationships between data may not be a central feature | Relationships between tables are a key feature  |
| Example: some file-based/database systems               | Examples: MySQL, Oracle, SQL Server, PostgreSQL |

### Remember:

> **Every RDBMS is a DBMS, but not every DBMS is an RDBMS.**

---

# 9. What is SQL?

**SQL** stands for:

> **Structured Query Language**

SQL is a **standard language used to communicate with relational database systems**.

We use SQL to write **SQL queries**.

### SQL is used to:

* Create database objects
* Insert data
* Read data
* Update data
* Delete data
* Control access
* Manage transactions

### Example:

```sql
SELECT * FROM students;
```

This query is used to retrieve data from the `students` table.

---

# 10. Is SQL a Database?

**No.**

SQL is **not a database** and it is **not a DBMS**.

SQL is a **language**.

For example:

* **SQL** → Language
* **MySQL** → RDBMS software
* **Database** → Collection of data

### Easy way to remember:

> **SQL is the language. MySQL is the software that uses SQL.**

---

# 11. SQL and RDBMS

RDBMS software uses SQL to manage data.

For example:

**User → SQL Query → MySQL → Database**

We write an SQL query, and the RDBMS executes that query to perform the required operation.

---

# 12. What is MySQL?

**MySQL** is an **open-source relational database management system (RDBMS)**.

It uses **SQL** to create, store, retrieve, update, and manage data.

### Simple definition:

> **MySQL is an RDBMS that uses SQL to manage data in relational databases.**

### Example:

We can use MySQL to create a student database:

```text
College Database
       ↓
Student Table
       ↓
ID | Name | Age | Marks
```

# 16. What is a Database Language?

A **database language** is a language used to communicate with and manage a database.

SQL is the most widely used language for relational databases.

Using SQL, we can perform operations such as:

* **Create**
* **Read**
* **Update**
* **Delete**

These four basic operations are commonly called **CRUD operations**.

### CRUD

| Operation | Meaning |
| --------- | ------- |
| C         | Create  |
| R         | Read    |
| U         | Update  |
| D         | Delete  |

---

# 17. Types of SQL Commands

SQL commands are commonly grouped into the following categories:

### 1. DDL – Data Definition Language

DDL is used to **define and modify the structure of database objects**, such as tables.

### Common DDL commands:

* `CREATE`
* `ALTER`
* `DROP`
* `TRUNCATE`

### Example:

```sql
CREATE TABLE students (
    id INT,
    name VARCHAR(50)
);
```

---

# 18. DML – Data Manipulation Language

DML is used to **insert, modify, and delete data** in tables.

### Common DML commands:

* `INSERT`
* `UPDATE`
* `DELETE`

### Example:

```sql
INSERT INTO students VALUES (101, 'Ravi');
```

---

# 19. DQL / DRL – Data Query or Data Retrieval Language

This is used to **retrieve or read data** from the database.

The main command is:

* `SELECT`

### Example:

```sql
SELECT * FROM students;
```

This retrieves the data from the `students` table.

> **Note:** Some textbooks call this **DRL (Data Retrieval Language)**, while many modern SQL references use **DQL (Data Query Language)**.

---

# 20. DCL – Data Control Language

DCL is used to **control access and permissions** in a database.

### Common commands:

* `GRANT`
* `REVOKE`

### Example:

```sql
GRANT SELECT ON students TO user1;
```

This can give a user permission to read data from the `students` table.

---

# 21. TCL – Transaction Control Language

TCL is used to **manage transactions** in a database.

### Common commands:

* `COMMIT`
* `ROLLBACK`
* `SAVEPOINT`

### Example:

```sql
COMMIT;
```

`COMMIT` permanently saves the changes made in the current transaction.

```sql
ROLLBACK;
```

`ROLLBACK` can undo changes that have not yet been committed.
