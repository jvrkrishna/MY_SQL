# SAVEPOINT

`SAVEPOINT` allows us to set a point in a transaction to which we can later roll back.

```text
BEGIN
  |
  |---- Savepoint 1
  |
  |---- Savepoint 2
  |
  |---- Savepoint n
  |
ROLLBACK
```

It is useful when we want to undo **part of a transaction** without rolling back the entire transaction.

## Syntax

```sql
SAVEPOINT savepoint_name;
```

---

## Practical Example

### Create Table

```sql
CREATE TABLE EMP_INFO (
    ID INT PRIMARY KEY,
    NAME VARCHAR(50),
    SALARY INT
);
```

### Insert Data

```sql
INSERT INTO EMP_INFO VALUES
(101, 'Ravi', 5500),
(102, 'Anita', 5800),
(103, 'Suman', 5900);
```

---

## Transaction with SAVEPOINT

### Step 1: Begin the Transaction

```sql
START TRANSACTION;
```

### Step 2: Make Some Updates

```sql
UPDATE EMP_INFO
SET SALARY = 5999
WHERE ID = 101;

UPDATE EMP_INFO
SET SALARY = 6000
WHERE ID = 103;
```

Check the current state:

```sql
SELECT * FROM EMP_INFO;
```

### Step 3: Set a Savepoint

```sql
SAVEPOINT sal_save;
```

### Step 4: Make Another Update

```sql
UPDATE EMP_INFO
SET NAME = 'RAJU'
WHERE ID = 103;
```

Check the state again:

```sql
SELECT * FROM EMP_INFO;
```

---

## Now We Have 3 Options

### Option 1: COMMIT

```sql
COMMIT;
```

This saves **all changes permanently**, including the name change from `SUMAN` to `RAJU`.

---

### Option 2: ROLLBACK Entire Transaction

```sql
ROLLBACK;
```

This undoes **everything in the current transaction**.

The salary changes and the name change will not persist.

---

### Option 3: ROLLBACK TO SAVEPOINT

```sql
ROLLBACK TO sal_save;
```

This undoes **only the changes made after the `sal_save` savepoint**.

The name change from `SUMAN` to `RAJU` is undone.

The salary changes remain.

The transaction is still active.

After rolling back to the savepoint, we can commit the remaining changes:

```sql
COMMIT;
```

---

## Final Check

```sql
SELECT * FROM EMP_INFO;
```

---

## Complete Practical Example

```sql
CREATE TABLE EMP_INFO (
    ID INT PRIMARY KEY,
    NAME VARCHAR(50),
    SALARY INT
);

INSERT INTO EMP_INFO VALUES
(101, 'Ravi', 5500),
(102, 'Anita', 5800),
(103, 'Suman', 5900);

START TRANSACTION;

UPDATE EMP_INFO
SET SALARY = 5999
WHERE ID = 101;

UPDATE EMP_INFO
SET SALARY = 6000
WHERE ID = 103;

SELECT * FROM EMP_INFO;

SAVEPOINT sal_save;

UPDATE EMP_INFO
SET NAME = 'RAJU'
WHERE ID = 103;

SELECT * FROM EMP_INFO;

ROLLBACK TO sal_save;

SELECT * FROM EMP_INFO;

COMMIT;

SELECT * FROM EMP_INFO;
```

## Key Point

```text
COMMIT
    → Saves all changes permanently.

ROLLBACK
    → Undoes the entire current transaction.

ROLLBACK TO SAVEPOINT
    → Undoes changes made after the specified savepoint.
```

### Result After `ROLLBACK TO sal_save`

|  ID | NAME  | SALARY |
| --: | ----- | -----: |
| 101 | Ravi  |   5999 |
| 102 | Anita |   5800 |
| 103 | Suman |   6000 |

The salary updates remain, while the `SUMAN → RAJU` name update is undone.
