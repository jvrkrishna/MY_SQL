# ROLLBACK TO

After setting a savepoint, you can roll back to it using the `ROLLBACK TO` command.

## Syntax

```sql
ROLLBACK TO savepoint_name;
```

## Example

```sql
ROLLBACK TO sal_save;
```

This will undo the changes made **after** the `sal_save` savepoint.

The changes made **before** the savepoint will remain in the transaction.

---

## Practical Example

```sql
START TRANSACTION;

UPDATE EMP_INFO
SET SALARY = 6000
WHERE ID = 101;

SAVEPOINT sal_save;

UPDATE EMP_INFO
SET SALARY = 7000
WHERE ID = 102;

SELECT * FROM EMP_INFO;

ROLLBACK TO sal_save;

SELECT * FROM EMP_INFO;
```

### After `ROLLBACK TO sal_save`

* The update to `ID = 102` is undone.
* The update to `ID = 101` remains.
* The transaction is still active.

---

## To Commit or Stop the Transaction

```sql
COMMIT;
```

`COMMIT` permanently saves the remaining changes and ends the current transaction.

## Key Point

```text
UPDATE before SAVEPOINT
        ↓
   SAVEPOINT
        ↓
UPDATE after SAVEPOINT
        ↓
ROLLBACK TO SAVEPOINT
        ↓
Only changes after SAVEPOINT are undone
        ↓
Transaction remains active
        ↓
COMMIT
        ↓
Remaining changes are saved permanently
```
