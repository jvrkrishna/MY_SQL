# ROLLBACK in MySQL

`ROLLBACK` is used to undo the changes made during the current transaction.

It rolls back the transaction to the point where the transaction started, discarding the modifications made during that transaction.

## Syntax

```sql
ROLLBACK;
```

## How to Rollback a Query in MySQL?

To use `ROLLBACK` for DML changes, start a transaction first.

> **Important:** Without an active transaction, you cannot use `ROLLBACK` to undo an already committed change.

## Practical Example

### Step 1: Start the Transaction

```sql
START TRANSACTION;
```

or:

```sql
BEGIN;
```

### Step 2: Update Data

```sql
UPDATE EMP
SET SALARY = 5000
WHERE ID = 101;
```

### Step 3: Check the Updated Data

```sql
SELECT * FROM EMP;
```

At this point, the update is part of the current transaction.

### Step 4: Rollback the Transaction

```sql
ROLLBACK;
```

The salary change made after `START TRANSACTION` is undone.

### Step 5: Check the Data Again

```sql
SELECT * FROM EMP;
```

The salary returns to its value before the transaction started.

# Practical Example: INSERT and UPDATE with ROLLBACK

## Step 1: Start the Transaction

```sql
START TRANSACTION;
```

## Step 2: Perform SQL Operations

```sql
INSERT INTO employee (NAME, DEPT)
VALUES ('Ram', 'Trainer');

UPDATE employee
SET DEPT = 'HR'
WHERE NAME = 'Ram';
```

## Step 3: Check the Changes

```sql
SELECT * FROM employee
WHERE NAME = 'Ram';
```

## Step 4: If Everything Is Correct, COMMIT

```sql
COMMIT;
```

The INSERT and UPDATE changes are permanently saved.

---

# If There Is an Error, Use ROLLBACK

Instead of committing, we can undo the transaction:

```sql
START TRANSACTION;

INSERT INTO employee (NAME, DEPT)
VALUES ('Ram', 'Trainer');

UPDATE employee
SET DEPT = 'HR'
WHERE NAME = 'Ram';

ROLLBACK;
```

Both the `INSERT` and `UPDATE` operations made after `START TRANSACTION` are rolled back.

---

# COMMIT vs ROLLBACK

```text
START TRANSACTION
       |
       +---- SQL Operations
       |
       +---- COMMIT
       |       ↓
       |   Changes permanently saved
       |
       +---- ROLLBACK
               ↓
           Changes undone
```

## COMMIT

```sql
START TRANSACTION;

UPDATE employee
SET DEPT = 'HR'
WHERE NAME = 'Ram';

COMMIT;
```

The change is permanently saved.

## ROLLBACK

```sql
START TRANSACTION;

UPDATE employee
SET DEPT = 'HR'
WHERE NAME = 'Ram';

ROLLBACK;
```

The change is undone.
