# INSERT Statement in MySQL

The INSERT statement is used to add new records (rows) into a table.

INSERT is a DML (Data Manipulation Language) command.

---

## 1. Insert Data into Specific Columns

We can specify the column names in the INSERT statement.

### Syntax

    INSERT INTO table_name (column1, column2, column3)
    VALUES (value1, value2, value3);

### Example

    INSERT INTO employee (ID, NAME, ADDRESS)
    VALUES (1, 'Ram', 'Kakinada');

To view the inserted data:

    SELECT * FROM employee;

---

## 2. Insert Data into All Columns

If we are inserting values into all columns of the table and the values are in the same order as the table columns, we can omit the column names.

### Syntax

    INSERT INTO table_name
    VALUES (value1, value2, value3);

### Example

Suppose the table is:

    CREATE TABLE employee (
        ID INT,
        NAME VARCHAR(30),
        ADDRESS VARCHAR(50)
    );

We can insert data as:

    INSERT INTO employee
    VALUES (2, 'Raj', 'Kakinada');

View the data:

    SELECT * FROM employee;

Important:
When the column list is omitted, the values must be supplied in the exact order of the columns in the table.

---

## 3. Insert Data into Selected Columns

We do not always have to provide values for every column.

We can specify only the columns for which we want to insert values.

### Example

    INSERT INTO employee (ID, NAME)
    VALUES (3, 'Ravi');

Here, no value is provided for ADDRESS.

If ADDRESS allows NULL, its value will be NULL.

    SELECT * FROM employee;

---

## 4. Insert Multiple Rows

We can insert multiple records using a single INSERT statement.

### Syntax

    INSERT INTO table_name (column1, column2, column3)
    VALUES
        (value1, value2, value3),
        (value1, value2, value3),
        (value1, value2, value3);

### Example

    INSERT INTO employee (ID, NAME, ADDRESS)
    VALUES
        (3, 'Ravi', 'Kakinada'),
        (4, 'Rani', 'Hyderabad'),
        (5, 'Raju', 'Vizag');

View the records:

    SELECT * FROM employee;

---

## 5. Insert Data with DEFAULT Value

If a column has a DEFAULT value, we can omit that column from the INSERT statement.

### Example

    CREATE TABLE student (
        ID INT,
        NAME VARCHAR(30),
        CITY VARCHAR(30) DEFAULT 'Kakinada'
    );

Insert data without specifying CITY:

    INSERT INTO student (ID, NAME)
    VALUES (1, 'Ravi');

View the data:

    SELECT * FROM student;

The CITY column will automatically receive the default value Kakinada.

---

## 6. INSERT with NULL

If a column allows NULL, we can explicitly insert NULL.

### Example

    INSERT INTO employee (ID, NAME, ADDRESS)
    VALUES (6, 'Anu', NULL);

View the data:

    SELECT * FROM employee;

The ADDRESS value will be NULL.

Important:
NULL means no value or unknown value.

NULL is not the same as:
- 0
- Empty string ''
- Space ' '

---

## 7. INSERT with AUTO_INCREMENT

If a column is defined as AUTO_INCREMENT, MySQL automatically generates its value.

### Example

    CREATE TABLE employee (
        ID INT PRIMARY KEY AUTO_INCREMENT,
        NAME VARCHAR(30),
        ADDRESS VARCHAR(50)
    );

Now we do not need to provide the ID.

    INSERT INTO employee (NAME, ADDRESS)
    VALUES ('Ram', 'Kakinada');

Another record:

    INSERT INTO employee (NAME, ADDRESS)
    VALUES ('Raj', 'Hyderabad');

MySQL automatically generates the ID values.

View the data:

    SELECT * FROM employee;

---

# Important Rules While Using INSERT

## 1. Values Must Match the Column Data Types

For example:

    ID INT

should normally receive a numeric value:

    INSERT INTO employee (ID)
    VALUES (10);

---

## 2. String Values Should Be Written Inside Quotes

Example:

    INSERT INTO employee (NAME)
    VALUES ('Ravi');

Single quotes are the standard SQL form for string values.

---

## 3. Primary Key Values Must Be Unique

Suppose:

    ID INT PRIMARY KEY

If ID = 1 already exists:

    INSERT INTO employee (ID, NAME)
    VALUES (1, 'Ravi');

This will fail because the primary key value 1 already exists.

---

## 4. NOT NULL Columns Must Receive a Value

Suppose:

    NAME VARCHAR(30) NOT NULL

This will fail:

    INSERT INTO employee (ID)
    VALUES (1);

because NAME cannot be NULL.

---

## 5. UNIQUE Columns Cannot Contain Duplicate Values

Suppose:

    EMAIL VARCHAR(100) UNIQUE

If an email already exists, inserting the same email again will fail.

---

## 6. FOREIGN KEY Values Must Refer to an Existing Parent Record

Suppose:

    FOREIGN KEY (DEPT_ID)
    REFERENCES department(ID)

If department 10 does not exist:

    INSERT INTO employee (ID, NAME, DEPT_ID)
    VALUES (1, 'Ravi', 10);

the insertion will normally fail because there is no matching department.

---

## 7. CHECK Conditions Must Be Satisfied

Suppose:

    AGE INT CHECK (AGE >= 18)

This will fail:

    INSERT INTO student (ID, NAME, AGE)
    VALUES (1, 'Ravi', 15);

because 15 does not satisfy the condition AGE >= 18.

# Practical Example

## Create Database

    CREATE DATABASE COLLEGE;

    USE COLLEGE;

## Create Table

    CREATE TABLE employee (
        ID INT PRIMARY KEY,
        NAME VARCHAR(30) NOT NULL,
        ADDRESS VARCHAR(50),
        AGE INT CHECK (AGE >= 18)
    );

## Insert First Record

    INSERT INTO employee (ID, NAME, ADDRESS, AGE)
    VALUES (1, 'Ram', 'Kakinada', 25);

## Insert Second Record

    INSERT INTO employee (ID, NAME, ADDRESS, AGE)
    VALUES (2, 'Raj', 'Hyderabad', 28);

## Insert Multiple Records

    INSERT INTO employee (ID, NAME, ADDRESS, AGE)
    VALUES
        (3, 'Ravi', 'Vizag', 22),
        (4, 'Rani', 'Chennai', 24),
        (5, 'Raju', 'Bangalore', 30);

## View All Records

    SELECT * FROM employee;

# INSERT Statement - Summary

| Method | Example |
|---|---|
| Insert into selected columns | INSERT INTO employee (ID, NAME) VALUES (1, 'Ram'); |
| Insert into all columns | INSERT INTO employee VALUES (1, 'Ram', 'Kakinada'); |
| Insert multiple rows | INSERT INTO employee (...) VALUES (...), (...), (...); |
| Insert NULL | INSERT INTO employee (...) VALUES (..., NULL); |
| Use DEFAULT value | Omit the column having a DEFAULT value |
| Use AUTO_INCREMENT | Omit the AUTO_INCREMENT column |

---

# Remember

- INSERT is used to add new rows.
- UPDATE is used to modify existing rows.
- DELETE is used to remove rows.
- SELECT is used to retrieve data.
