# UPDATE Statement in MySQL

The `UPDATE` statement is used to **modify existing records (rows) in a table**.

`UPDATE` is a **DML (Data Manipulation Language)** command.

We can use the `UPDATE` statement to modify:
- One column
- Multiple columns
- One record
- Multiple records
- All records

---

## 1. Update a Single Column

We can update one column of an existing record.

### Syntax

    UPDATE table_name
    SET column_name = new_value
    WHERE condition;

### Example

    UPDATE stud_info
    SET COURSE = 'MCA'
    WHERE ID = 1;

This changes the `COURSE` of the employee/student whose `ID` is `1` to `MCA`.

To view the updated data:

    SELECT * FROM stud_info;

---

## 2. Update Multiple Columns

We can update more than one column in a single `UPDATE` statement.

### Syntax

    UPDATE table_name
    SET column_name1 = new_value1,
        column_name2 = new_value2
    WHERE condition;

### Example

    UPDATE stud_info
    SET COURSE = 'MCA',
        NAME = 'RAMA'
    WHERE ID = 1;

This changes both `COURSE` and `NAME` for the record whose `ID` is `1`.

---

## 3. UPDATE Using a Condition

The `WHERE` clause is used to identify which records should be updated.

### Example

    UPDATE EMP_INFO
    SET SALARY = 23000
    WHERE NAME = 'Raju';

Only the employee whose name is `Raju` will be updated.

---

## 4. UPDATE Without WHERE Clause

If we do not use a `WHERE` clause, the `UPDATE` statement will modify **all rows in the table**.

### Example

    UPDATE EMP_INFO
    SET SALARY = SALARY + 3300;

This adds `3300` to the salary of every employee.

### Important

Always be careful when using `UPDATE` without a `WHERE` clause.

Example:

    UPDATE EMP_INFO
    SET SALARY = 25000;

This will set the salary of **every employee** to `25000`.

# UPDATE Queries

## Q1. Add 3300 to All Employee Salaries

    UPDATE EMP_INFO
    SET SALARY = SALARY + 3300;

View the updated records:

    SELECT * FROM EMP_INFO;

### Explanation

The existing salary is increased by `3300`.

For example:

    Old Salary = 25000
    New Salary = 25000 + 3300
    New Salary = 28300

Because there is no `WHERE` clause, all employees are updated.

---

## Q2. Update Raju's Salary to 23000

    UPDATE EMP_INFO
    SET SALARY = 23000
    WHERE NAME = 'Raju';

View the records:

    SELECT * FROM EMP_INFO;

### Explanation

Only the employee whose `NAME` is `Raju` will have the salary changed to `23000`.

---

## Q3. Add 1500 to the Salary of the Employee Who Joined on 2020-08-12

    UPDATE EMP_INFO
    SET SALARY = SALARY + 1500
    WHERE JDATE = '2020-08-12';

View the records:

    SELECT * FROM EMP_INFO;

### Explanation

The salary of the employee whose joining date is `2020-08-12` will be increased by `1500`.

---

## Q4. Add 2100 to Employees Earning Less Than 27000

    UPDATE EMP_INFO
    SET SALARY = SALARY + 2100
    WHERE SALARY < 27000;

View the records:

    SELECT * FROM EMP_INFO;

### Explanation

Only employees whose salary is less than `27000` will receive an increase of `2100`.

---

# 5. Update Multiple Columns

We can modify multiple columns at the same time.

### Example

    UPDATE EMP_INFO
    SET NAME = 'RAMA',
        SALARY = 30000
    WHERE ID = 1;

This changes:
- `NAME` to `RAMA`
- `SALARY` to `30000`

for the employee whose `ID` is `1`.

---

# 6. Update Using Multiple Conditions

We can use `AND` and `OR` with the `WHERE` clause.

### Using AND

    UPDATE EMP_INFO
    SET SALARY = SALARY + 2000
    WHERE SALARY < 30000
    AND ID > 1;

Both conditions must be satisfied.

### Using OR

    UPDATE EMP_INFO
    SET SALARY = SALARY + 2000
    WHERE NAME = 'Ram'
    OR NAME = 'Ravi';

The salary will be increased for employees whose name is either `Ram` or `Ravi`.

---

# 7. Update a Date Column

We can also update date values.

### Example

    UPDATE EMP_INFO
    SET JDATE = '2021-01-15'
    WHERE ID = 1;

This changes the joining date of employee `1`.

---

# 8. Update a String Column

String values should be written inside single quotes.

### Example

    UPDATE EMP_INFO
    SET NAME = 'Ramesh'
    WHERE ID = 1;

---

# 9. Update a Column to NULL

If the column allows `NULL`, we can set its value to `NULL`.

### Example

    UPDATE EMP_INFO
    SET SALARY = NULL
    WHERE ID = 1;

The salary of employee `1` becomes `NULL`.

Important:

`NULL` means no value or unknown value.

It is not the same as:

    0

or:

    ''

---

# 10. UPDATE Using Arithmetic Operators

We can perform calculations while updating values.

### Increase Salary

    UPDATE EMP_INFO
    SET SALARY = SALARY + 1000
    WHERE ID = 1;

### Decrease Salary

    UPDATE EMP_INFO
    SET SALARY = SALARY - 1000
    WHERE ID = 1;

### Increase Salary by 10%

    UPDATE EMP_INFO
    SET SALARY = SALARY + (SALARY * 10 / 100)
    WHERE ID = 1;

---

# SQL Safe Update Mode

MySQL Workbench may prevent some `UPDATE` or `DELETE` statements when Safe Update Mode is enabled.

For example:

    UPDATE EMP_INFO
    SET SALARY = SALARY + 3300;

may produce a safe-update error in some configurations because there is no `WHERE` clause using a key column.

To temporarily disable safe update mode for the current session:

    SET SQL_SAFE_UPDATES = 0;

Then execute:

    UPDATE EMP_INFO
    SET SALARY = SALARY + 3300;

Important:

Disabling safe update mode is not required for normal `UPDATE` statements when an appropriate `WHERE` clause is used.

After making changes, you can verify the data:

    SELECT * FROM EMP_INFO;

---

# Important Points About UPDATE

- `UPDATE` is a **DML command**.
- It is used to **modify existing records**.
- `SET` specifies the new values.
- `WHERE` specifies which records should be updated.
- Without `WHERE`, all rows may be updated.
- Multiple columns can be updated in one statement.
- Multiple rows can be updated using a condition.
- We can use arithmetic expressions while updating numeric values.
- String values should normally be written inside single quotes.
- Date values are generally written in `YYYY-MM-DD` format.
- Always check the `WHERE` condition carefully before executing an `UPDATE`.
