# DELETE Statement in MySQL

The `DELETE` statement is used to **remove existing records (rows) from a table**.

`DELETE` is a **DML (Data Manipulation Language)** command.

We can use `DELETE` to:
- Delete a specific record
- Delete multiple records
- Delete all records from a table

---

## 1. DELETE Specific Records

We use the `WHERE` clause to specify which records should be deleted.

### Syntax

    DELETE FROM table_name
    WHERE condition;

### Example

    DELETE FROM EMP_INFO
    WHERE ID = 1;

This deletes the employee whose `ID` is `1`.

To check the remaining records:

    SELECT * FROM EMP_INFO;

---

## 2. DELETE Multiple Records

If the `WHERE` condition matches multiple rows, all matching rows will be deleted.

### Example

    DELETE FROM EMP_INFO
    WHERE SALARY < 10000;

This deletes all employees whose salary is less than `10000`.

---

## 3. DELETE All Records

If we omit the `WHERE` clause, all records from the table will be deleted.

### Syntax

    DELETE FROM table_name;

### Example

    DELETE FROM EMP_INFO;

This removes all rows from `EMP_INFO`.

Important:

The table structure is not deleted.

The table still exists and can be used again.

To check:

    DESC EMP_INFO;

---

# DELETE Queries

## Q1. Delete Employees with Salary Below 10,000

    DELETE FROM EMP_INFO
    WHERE SALARY < 10000;

View the remaining records:

    SELECT * FROM EMP_INFO;

### Explanation

Only employees whose salary is less than `10000` will be deleted.

---

## Q2. Delete Employees with Salary Between 60,000 and 76,000

    DELETE FROM EMP_INFO
    WHERE SALARY > 60000
    AND SALARY < 76000;

View the remaining records:

    SELECT * FROM EMP_INFO;

### Explanation

Employees whose salary is greater than `60000` and less than `76000` will be deleted.

In the given data:

- Rahul → `75000` → Deleted
- Raghu → `61000` → Deleted

---

## Q3. Delete the Employee Named 'Ram'

    DELETE FROM EMP_INFO
    WHERE NAME = 'Ram';

View the remaining records:

    SELECT * FROM EMP_INFO;

### Explanation

The employee whose `NAME` is `Ram` will be deleted.

---

## Q4. Delete Records Based on Multiple Conditions

We can use `AND` and `OR` with the `WHERE` clause.

### Using AND

    DELETE FROM EMP_INFO
    WHERE SALARY < 30000
    AND ID > 1;

Both conditions must be satisfied.

### Using OR

    DELETE FROM EMP_INFO
    WHERE NAME = 'Ram'
    OR NAME = 'Ravi';

Employees named `Ram` or `Ravi` will be deleted.

---

## Q5. Delete All Records

    DELETE FROM EMP_INFO;

View the table:

    SELECT * FROM EMP_INFO;

The result will contain no rows, but the table itself still exists.

We can verify the table structure:

    DESC EMP_INFO;

---

# 4. DELETE Without WHERE Clause

This is very important.

Consider:

    DELETE FROM EMP_INFO;

There is no `WHERE` clause.

Therefore, **all rows will be deleted**.

The table structure remains.

Be careful before executing a `DELETE` statement without a `WHERE` clause.

---

# 5. DELETE with Comparison Operators

We can use comparison operators with `WHERE`.

### Greater Than

    DELETE FROM EMP_INFO
    WHERE SALARY > 50000;

Deletes employees earning more than `50000`.

### Less Than

    DELETE FROM EMP_INFO
    WHERE SALARY < 20000;

Deletes employees earning less than `20000`.

### Equal To

    DELETE FROM EMP_INFO
    WHERE ID = 3;

Deletes the employee whose ID is `3`.

### Not Equal To

    DELETE FROM EMP_INFO
    WHERE ID <> 3;

Deletes all employees except the employee whose ID is `3`.

---

# 6. DELETE Using BETWEEN

`BETWEEN` is used to check whether a value falls within a range.

### Example

    DELETE FROM EMP_INFO
    WHERE SALARY BETWEEN 20000 AND 50000;

This deletes employees whose salary is between `20000` and `50000`.

Important:

`BETWEEN` is inclusive.

That means:

    BETWEEN 20000 AND 50000

includes both `20000` and `50000`.

---

# 7. DELETE Using IN

`IN` is used when we want to match multiple values.

### Example

    DELETE FROM EMP_INFO
    WHERE ID IN (1, 3, 5);

This deletes employees whose ID is `1`, `3`, or `5`.

---

# 8. DELETE Using LIKE

`LIKE` is used for pattern matching.

### Example

    DELETE FROM EMP_INFO
    WHERE NAME LIKE 'Ra%';

This deletes employees whose names start with `Ra`.

Examples:

    'Ra%'     -> Starts with Ra

    '%am'     -> Ends with am

    '%av%'    -> Contains av

---

# 9. DELETE Records with NULL Values

We should use `IS NULL` to find NULL values.

### Example

    DELETE FROM EMP_INFO
    WHERE SALARY IS NULL;

This deletes records where `SALARY` is `NULL`.

Do not use:

    SALARY = NULL

Use:

    SALARY IS NULL

---

# 10. DELETE Duplicate Records

If a table does not have a `PRIMARY KEY` or `UNIQUE` constraint, duplicate records may exist.

For example, suppose duplicate names exist.

A self-join technique can be used to remove duplicate records while keeping the record with the smaller ID.

### Example

    DELETE e1
    FROM EMP_INFO e1, EMP_INFO e2
    WHERE e1.NAME = e2.NAME
    AND e1.ID > e2.ID;

### Explanation

Here:

- `e1` represents one copy of the record.
- `e2` represents another copy.
- Records having the same `NAME` are compared.
- The record with the larger `ID` is deleted.
- The record with the smaller `ID` is kept.

Important:

This is an advanced technique.

It is better to prevent duplicate data by using appropriate constraints such as:

    PRIMARY KEY

and

    UNIQUE

# DELETE vs TRUNCATE

Both `DELETE` and `TRUNCATE` can remove rows from a table, but they work differently.

| Feature | DELETE | TRUNCATE |
|---|---|---|
| Command type | DML | DDL |
| Removes rows | Yes | Yes |
| Removes table structure | No | No |
| WHERE clause | Yes | No |
| Delete selected rows | Yes | No |
| Delete all rows | Yes | Yes |
| Speed for large tables | Generally slower | Generally faster |
| Row-by-row deletion | Yes | No |
| DELETE triggers | Can fire | Does not fire DELETE triggers |
| Auto-increment reset | Normally not reset by DELETE | Normally reset |
| Transaction rollback | Can be rolled back before commit | In MySQL, generally cannot be rolled back |

---

# DELETE vs TRUNCATE vs DROP

These three commands are different.

## DELETE

    DELETE FROM EMP_INFO
    WHERE ID = 1;

- Removes selected rows.
- Uses `WHERE`.
- Table structure remains.
- Can also remove all rows if `WHERE` is omitted.

## TRUNCATE

    TRUNCATE TABLE EMP_INFO;

- Removes all rows.
- Cannot use `WHERE`.
- Table structure remains.
- Generally faster for removing all rows.

## DROP

    DROP TABLE EMP_INFO;

- Removes the entire table.
- Removes both the table structure and its data.
- After `DROP`, the table no longer exists.

---

# Important Points About DELETE

- `DELETE` is a **DML command**.
- It is used to remove existing rows.
- `WHERE` is used to select which rows should be deleted.
- If `WHERE` is omitted, all rows are deleted.
- The table structure remains after `DELETE`.
- `DELETE` can delete one row or many rows.
- `DELETE` can be used with conditions such as `=`, `>`, `<`, `>=`, `<=`, `<>`, `BETWEEN`, `IN`, and `LIKE`.
- Use `IS NULL` to delete rows containing `NULL`.
- Always check the `WHERE` condition before executing `DELETE`.
- Be especially careful with `DELETE` statements that do not have a `WHERE` clause.
