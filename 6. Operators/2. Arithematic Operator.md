# Arithmetic Operators (+, -, *, /)

Arithmetic operators are used to perform mathematical calculations on numeric values.

- `+` → Addition
- `-` → Subtraction
- `*` → Multiplication
- `/` → Division

---

## 1. Create Database

    CREATE DATABASE CompanyDB;

---

## 2. Use the Database

    USE CompanyDB;

---

## 3. Create Employee Table

    CREATE TABLE Employee (
        EmpID INT PRIMARY KEY,
        Name VARCHAR(50),
        Sal DECIMAL(10,2)
    );

---

## 4. Insert Sample Data

    INSERT INTO Employee (EmpID, Name, Sal) VALUES
    (101, 'Ravi', 30000),
    (102, 'Sita', 45000),
    (103, 'Amit', 25000),
    (104, 'Priya', 52000),
    (105, 'Rahul', 40000);

---

## 5. View Table Data

    SELECT * FROM Employee;

### Output

| EmpID | Name | Sal |
|------:|------|----:|
| 101 | Ravi | 30000 |
| 102 | Sita | 45000 |
| 103 | Amit | 25000 |
| 104 | Priya | 52000 |
| 105 | Rahul | 40000 |

# Arithmetic Operator Queries

## Q1. Employee Name, Salary and Annual Salary

    SELECT Name, Sal, Sal * 12 AS Annual_Salary
    FROM Employee;

### Explanation

Annual salary is calculated by multiplying monthly salary by 12.

    Annual Salary = Monthly Salary × 12

---

## Q2. Employee Name, Salary and Daily Salary

    SELECT Name, Sal, Sal / 30 AS Daily_Salary
    FROM Employee;

### Explanation

Daily salary is calculated by dividing monthly salary by 30.

    Daily Salary = Monthly Salary ÷ 30

---

## Q3. Employee Name, Salary and 10% of Salary as Bonus

    SELECT Name, Sal, 0.10 * Sal AS Bonus
    FROM Employee;

### Explanation

    Bonus = 10% of Salary

---

## Q4. Employee Name, Salary and 10% Bonus with Title

    SELECT Name, Sal, 0.10 * Sal AS "10% Bonus"
    FROM Employee;

### Explanation

`AS` is used to give an alias (heading) to the calculated column.

Here:

- `0.10 * Sal` → Calculates 10% of salary
- `AS` → Gives an alias
- `"10% Bonus"` → Alias / column heading

---

## Q5. Employee Name, Salary and 5% Salary as TA

### Answer

    SELECT Name, Sal, 0.05 * Sal AS "TA"
    FROM Employee;

### Explanation

    TA = 5% of Salary

---

## Q6. Employee Salary as Basic Salary and Calculate Allowances

    SELECT
        Name,
        Sal AS "BASIC SALARY",
        0.03 * Sal AS "TA",
        0.06 * Sal AS "DA",
        0.12 * Sal AS "HRA",
        0.08 * Sal AS "COMM"
    FROM Employee;

### Explanation

    TA   = 3% of Salary
    DA   = 6% of Salary
    HRA  = 12% of Salary
    COMM = 8% of Salary
