# MySQL Operators

## What is an Operator?

Operators are mathematical symbols or reserved words in MySQL that are used to perform operations on operands.

### What is an Operand?

An **operand** is the data or value on which an operator performs an operation.

### Example

```sql
10 + 20 
```

Types of Operators in MySQL

MySQL operators are generally classified into the following categories:

Arithmetic Operators
Relational Operators
Logical Operators
Set Operators
Special Operators
