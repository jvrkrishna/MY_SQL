# Relational Operators

Relational operators are used to compare two values.

Common relational operators in MySQL are:

- `<`  → Less than
- `>`  → Greater than
- `=`  → Equal to
- `<=` → Less than or equal to
- `>=` → Greater than or equal to
- `<>` → Not equal to

Relational operators are commonly used along with the `WHERE` clause to filter records.

---

## 1. Create Database

    CREATE DATABASE CompanyDB;

---

## 2. Use Database

    USE CompanyDB;

---

## 3. Create Employee Table

    CREATE TABLE EMP_INFO (
        EMP_ID INT PRIMARY KEY,
        NAME VARCHAR(50),
        SAL INT,
        JDATE DATE
    );

# Relational Operator Queries

## Q1. Employee Details Having Salary Less Than 25,000

    SELECT *
    FROM EMP_INFO
    WHERE SAL < 25000;

### Explanation

`<` means **less than**.

The query displays employees whose salary is less than `25000`.

---

## Q2. Employee Details Having Salary Less Than or Equal to 25,000

    SELECT *
    FROM EMP_INFO
    WHERE SAL <= 25000;

### Explanation

`<=` means **less than or equal to**.

The query displays employees whose salary is either less than or exactly `25000`.

---

## Q3. Employee Details Having Salary Equal to 75,000

    SELECT *
    FROM EMP_INFO
    WHERE SAL = 75000;

### Explanation

`=` means **equal to**.

The query displays employees whose salary is exactly `75000`.

---

## Q4. Employee Details Who Are Not Getting 40,000

    SELECT *
    FROM EMP_INFO
    WHERE NOT SAL = 40000;

### Alternative

The `<>` operator can be used directly for **not equal to**.

    SELECT *
    FROM EMP_INFO
    WHERE SAL <> 40000;

### Explanation

`<>` means **not equal to**.

The query displays employees whose salary is not `40000`.

---

## Q5. Employee Details Whose Name is RAM

    SELECT *
    FROM EMP_INFO
    WHERE NAME = 'RAM';

### Explanation

The `=` operator is used to compare the employee's name with the value `'RAM'`.

String values are written inside quotes.

---

## Q6. Employee Details Who Joined on 22nd October 2022

    SELECT *
    FROM EMP_INFO
    WHERE JDATE = '2022-10-22';

### Explanation

The `=` operator is used to compare the `JDATE` column with the given date.

MySQL commonly uses the date format:

    YYYY-MM-DD

Example:

    '2022-10-22'
