# Set Operators in MySQL

Set Operators allow you to combine the results of two or more SELECT statements into a single result set based on set theory principles.

These operators allow you to perform operations such as:

- Combining sets of data
- Finding common data between sets
- Finding differences between sets

## Rules to Use Set Operators

1. Every SELECT statement must have the same number of columns.
2. The columns must have similar or compatible data types.
3. The columns in every SELECT statement must be in the same order.

## Set Operators

- UNION
- UNION ALL
- INTERSECT
- EXCEPT / MINUS

# 1. UNION Operator

The UNION operator combines the results of two or more SELECT statements.

It removes duplicate rows from the final result.

## Syntax

    SELECT column1, column2
    FROM table1

    UNION

    SELECT column1, column2
    FROM table2;

## Practical Example

### Question:

Display all employee and manager records without duplicates.

    SELECT id, name, salary, department, dob
    FROM employee

    UNION

    SELECT id, manager_name, salary, department, dob
    FROM manager;

### Explanation

- The first SELECT gets records from the employee table.
- The second SELECT gets records from the manager table.
- UNION combines both results.
- Duplicate rows are removed.

---

# 2. UNION ALL Operator

The UNION ALL operator combines the results of two or more SELECT statements.

Unlike UNION, it does not remove duplicate rows.

## Syntax

    SELECT column1, column2
    FROM table1

    UNION ALL

    SELECT column1, column2
    FROM table2;

## Practical Example

### Question:

Display all employee and manager records, including duplicates.

    SELECT id, name, salary, department, dob
    FROM employee

    UNION ALL

    SELECT id, manager_name, salary, department, dob
    FROM manager;

### Explanation

- All records from both SELECT statements are returned.
- Duplicate records are also included.
- UNION ALL is generally faster than UNION because it does not perform duplicate elimination.

---

# 3. EXCEPT Operator

The EXCEPT operator returns rows that are present in the first SELECT result but not in the second SELECT result.

## Syntax

    SELECT column1, column2
    FROM table1

    EXCEPT

    SELECT column1, column2
    FROM table2;

## Practical Example

### Question:

Find employees who are NOT managers.

    SELECT id, name, salary, department, dob
    FROM employee

    EXCEPT

    SELECT id, manager_name, salary, department, dob
    FROM manager;

### Explanation

- The first query returns employee records.
- The second query returns manager records.
- EXCEPT removes rows that are common to both results.
- The remaining rows belong only to the first result.

### Important Note

MySQL versions before 8.0.31 do not support the EXCEPT operator.

In Oracle, the equivalent operator is:

    MINUS

---

# 4. INTERSECT Operator

The INTERSECT operator returns the rows that are common to both SELECT results.

## Syntax

    SELECT column1, column2
    FROM table1

    INTERSECT

    SELECT column1, column2
    FROM table2;

## Practical Example

### Question:

Find employees who are also managers.

    SELECT id, name, salary, department, dob
    FROM employee

    INTERSECT

    SELECT id, manager_name, salary, department, dob
    FROM manager;

### Explanation

- The first SELECT returns employee records.
- The second SELECT returns manager records.
- INTERSECT returns only the rows that are common to both result sets.

### Important Note

MySQL supports INTERSECT in MySQL 8.0.31 and later.

---

# 5. INTERSECT with Condition

Set operators can be combined with WHERE conditions.

### Question:

Find employees who are also managers where the employee ID is greater than 104.

    SELECT id, name, salary, department, dob
    FROM employee
    WHERE id > 104

    INTERSECT

    SELECT id, manager_name, salary, department, dob
    FROM manager;

### Explanation

The first SELECT first filters employees whose ID is greater than 104.

Then INTERSECT finds the records that are also present in the manager result.

# Set Operators Comparison

| Operator | Purpose |
|----------|---------|
| UNION | Combines results and removes duplicates |
| UNION ALL | Combines results and keeps duplicates |
| INTERSECT | Returns common rows from both queries |
| EXCEPT | Returns rows from the first query that are not in the second |
| MINUS | Oracle equivalent of EXCEPT |

---

# Important Rules

1. Both SELECT statements must return the same number of columns.
2. Corresponding columns should have compatible data types.
3. Columns must appear in the same order.
4. Column names of the final result are generally taken from the first SELECT statement.
5. UNION removes duplicate rows.
6. UNION ALL keeps duplicate rows.
7. INTERSECT returns common rows.
8. EXCEPT returns rows from the first query that are not present in the second query.
9. EXCEPT is available in MySQL 8.0.31 and later.
10. INTERSECT is available in MySQL 8.0.31 and later.
11. Oracle uses MINUS instead of EXCEPT.

# Basic Difference

## UNION

Result = A + B

Duplicates removed.

## UNION ALL

Result = A + B

Duplicates retained.

## INTERSECT

Result = Common rows between A and B.

## EXCEPT

Result = Rows in A but not in B.
