# Set Operators in MySQL

Set operators are used to combine the results of two or more `SELECT` statements into a single result set.

These operators perform operations based on set theory, such as:

- Combining two result sets
- Finding common records
- Finding records that exist in one result set but not another

---

# Rules to Use Set Operators

When using set operators, the following rules should be followed:

1. Every `SELECT` statement must return the same number of columns.
2. The corresponding columns must have compatible or similar data types.
3. The columns must appear in the same order in every `SELECT` statement.
4. The column names of the final result are generally taken from the first `SELECT` statement.
5. `ORDER BY`, when required for the complete result, is generally placed at the end of the complete set operation.

---

# Set Operators

The commonly used set operators are:

1. `UNION`
2. `UNION ALL`
3. `INTERSECT`
4. `EXCEPT`

> **Note:** `MINUS` is used instead of `EXCEPT` in Oracle. MySQL supports `EXCEPT` in current versions; older MySQL versions did not support `INTERSECT` and `EXCEPT`.
