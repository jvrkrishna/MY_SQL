# BETWEEN and NOT BETWEEN Operator

The BETWEEN operator is used to select values within a specified range.

BETWEEN includes both boundary values.

For example:

    SAL BETWEEN 25000 AND 50000

is equivalent to:

    SAL >= 25000 AND SAL <= 50000

## Syntax

    SELECT column_name
    FROM table_name
    WHERE column_name BETWEEN value1 AND value2;

## 1. Employees with salary between 25000 and 50000

    SELECT *
    FROM EMP_INFO
    WHERE SAL BETWEEN 25000 AND 50000;

Both 25000 and 50000 are included.

## 2. Employees with salary between 25000 and 60000, excluding 60000

    SELECT NAME, SAL
    FROM EMP_INFO
    WHERE SAL BETWEEN 25000 AND 59999;

Alternative:

    SELECT NAME, SAL
    FROM EMP_INFO
    WHERE SAL >= 25000
    AND SAL < 60000;

## 3. Employees who joined in 2019

    SELECT *
    FROM EMP_INFO
    WHERE JDATE BETWEEN '2019-01-01' AND '2019-12-31';

## 4. Employees who did NOT join in 2019

    SELECT *
    FROM EMP_INFO
    WHERE JDATE NOT BETWEEN '2019-01-01' AND '2019-12-31';

## Important Point

BETWEEN is inclusive.

    SAL BETWEEN 25000 AND 50000

means:

    SAL >= 25000 AND SAL <= 50000

# IN and NOT IN Operator

The IN operator is used to match a column against multiple specific values.

Instead of writing multiple OR conditions, we can use IN.

## Syntax

    SELECT column_name
    FROM table_name
    WHERE column_name IN (value1, value2, value3);

## 1. Employees who joined on 26-Jan-2019 or 16-Aug-2019

    SELECT *
    FROM EMP_INFO
    WHERE JDATE IN ('2019-01-26', '2019-08-16');

This is equivalent to:

    SELECT *
    FROM EMP_INFO
    WHERE JDATE = '2019-01-26'
    OR JDATE = '2019-08-16';

## 2. Employees who did NOT join on those dates

    SELECT *
    FROM EMP_INFO
    WHERE JDATE NOT IN ('2019-01-26', '2019-08-16');

## 3. Employees whose salary is 25000, 50000, or 75000

    SELECT *
    FROM EMP_INFO
    WHERE SAL IN (25000, 50000, 75000);

## Important Point

IN checks for exact matching.

    SAL IN (25000, 50000, 75000)

is equivalent to:

    SAL = 25000
    OR SAL = 50000
    OR SAL = 75000

# LIKE and NOT LIKE Operator

The LIKE operator is used for pattern matching.

It is commonly used with character columns such as:

- NAME
- EMAIL
- ADDRESS

## Wildcard Characters

| Symbol | Meaning |
|--------|---------|
| % | Zero or more characters |
| _ | Exactly one character |

## Important Point

% can represent zero or more characters.

_ represents exactly one character.

---

## 1. Employees with 4-digit salary

Since SAL is an integer column, a numeric condition is preferred:

    SELECT *
    FROM EMP_INFO
    WHERE SAL BETWEEN 1000 AND 9999;

If you specifically want to demonstrate LIKE:

    SELECT *
    FROM EMP_INFO
    WHERE CAST(SAL AS CHAR) LIKE '____';

Each _ represents exactly one character.

## 2. Employees NOT having a 4-digit salary

Numeric method:

    SELECT *
    FROM EMP_INFO
    WHERE SAL NOT BETWEEN 1000 AND 9999;

Using LIKE:

    SELECT *
    FROM EMP_INFO
    WHERE CAST(SAL AS CHAR) NOT LIKE '____';

## 3. Employees whose salary starts with 5

    SELECT *
    FROM EMP_INFO
    WHERE CAST(SAL AS CHAR) LIKE '5%';

## 4. Employees whose name starts with S

    SELECT *
    FROM EMP_INFO
    WHERE NAME LIKE 'S%';

## 5. Employees whose name ends with a

    SELECT *
    FROM EMP_INFO
    WHERE NAME LIKE '%a';

## 6. Employees whose name ends with nka

    SELECT *
    FROM EMP_INFO
    WHERE NAME LIKE '%nka';

## 7. Employees whose name starts with P and ends with a

    SELECT *
    FROM EMP_INFO
    WHERE NAME LIKE 'P%a';

## 8. Employees whose name contains u

    SELECT *
    FROM EMP_INFO
    WHERE NAME LIKE '%u%';

## 9. Employees with a name of 8 characters and second letter u

    SELECT *
    FROM EMP_INFO
    WHERE NAME LIKE '_u______';

Explanation:

    _       = 1st character
    u       = 2nd character
    ______  = remaining 6 characters

Therefore, the pattern contains exactly 8 characters.

## 10. Employees who joined in 2020

For a DATE column, a date range is preferred:

    SELECT *
    FROM EMP_INFO
    WHERE JDATE BETWEEN '2020-01-01' AND '2020-12-31';

You can also use:

    SELECT *
    FROM EMP_INFO
    WHERE JDATE LIKE '2020%';

## 11. Employees whose name starts with S and has exactly 4 characters

    SELECT *
    FROM EMP_INFO
    WHERE NAME LIKE 'S___';

Explanation:

    S    = first character
    ___  = exactly three more characters

Therefore, the name must contain exactly four characters.

# IS NULL and IS NOT NULL Operator

NULL represents the absence of a value.

NULL is NOT:

    0

NULL is NOT:

    ''

NULL is NOT:

    'NULL'

To check for NULL, use:

    IS NULL

To check for a value that is not NULL, use:

    IS NOT NULL

Do not use:

    = NULL

or:

    <> NULL

for NULL checking.

---

## 1. Employees whose EMAIL is NULL

    SELECT *
    FROM EMP_INFO
    WHERE EMAIL IS NULL;

## 2. Employees whose EMAIL and ADDRESS are NULL

    SELECT *
    FROM EMP_INFO
    WHERE EMAIL IS NULL
    AND ADDRESS IS NULL;

## 3. Employees whose EMAIL is NOT NULL

    SELECT *
    FROM EMP_INFO
    WHERE EMAIL IS NOT NULL;

## 4. Employees whose ADDRESS is NOT NULL

    SELECT *
    FROM EMP_INFO
    WHERE ADDRESS IS NOT NULL;

## 5. Employees whose EMAIL is NULL or ADDRESS is NULL

    SELECT *
    FROM EMP_INFO
    WHERE EMAIL IS NULL
    OR ADDRESS IS NULL;

# Practical Combination Examples

## 1. Employees with salary between 25000 and 60000 and EMAIL available

    SELECT *
    FROM EMP_INFO
    WHERE SAL BETWEEN 25000 AND 60000
    AND EMAIL IS NOT NULL;

## 2. Employees whose name starts with S and salary is greater than 25000

    SELECT *
    FROM EMP_INFO
    WHERE NAME LIKE 'S%'
    AND SAL > 25000;

## 3. Employees whose salary is 25000, 50000, or 75000 and address is available

    SELECT *
    FROM EMP_INFO
    WHERE SAL IN (25000, 50000, 75000)
    AND ADDRESS IS NOT NULL;

## 4. Employees who did not join in 2019 and have an email

    SELECT *
    FROM EMP_INFO
    WHERE JDATE NOT BETWEEN '2019-01-01' AND '2019-12-31'
    AND EMAIL IS NOT NULL;

## 5. Employees whose name contains u and salary is between 20000 and 60000

    SELECT *
    FROM EMP_INFO
    WHERE NAME LIKE '%u%'
    AND SAL BETWEEN 20000 AND 60000;
