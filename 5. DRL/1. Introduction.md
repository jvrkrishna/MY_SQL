Data Retrieval Language (DRL)

DRL stands for Data Retrieval Language.

DRL is a sub-language of SQL.

DRL is used to retrieve data from a table.

The SELECT command is used in DRL.

SELECT Command

Select Specific Columns

SELECT <col_1>, <col_2> FROM <table_name>;

Example:

SELECT name, salary FROM Employee;

Select All Columns

SELECT * FROM <table_name>;

Example:

SELECT * FROM Employee;

SELECT Command with WHERE Clause

SELECT <col_1>, <col_2>
FROM <table_name>
WHERE condition;

Practical

Create the Employee Table

CREATE TABLE Employee (
    ID INT PRIMARY KEY AUTO_INCREMENT,  -- Optional, to uniquely identify each employee
    NAME VARCHAR(100),
    SAL DECIMAL(10, 2),
    JDATE DATE
);

Insert Data

INSERT INTO Employee (NAME, SAL, JDATE) VALUES 
('Alice', 32000.50, '2022-01-10'),
('Bob', 28000.00, '2021-07-01'),
('Charlie', 35000.75, '2020-11-20'),
('Ram', 30000.00, '2023-03-15');

Questions and Queries

Q1. Select the name and salary of all employees.

SELECT NAME, SAL FROM Employee;

Q2. Select the name and joining date of all employees who joined after 2021-08-15.

SELECT NAME, JDATE FROM Employee;

SELECT NAME, JDATE
FROM Employee
WHERE JDATE > '2021-08-15';

Q3. Select all employees who joined after 2020.

SELECT NAME, JDATE
FROM Employee
WHERE JDATE > '2020-12-31';

SELECT with Constant Values and Expressions

SELECT 6 FROM Employee;

SELECT 6 * 6 FROM Employee;

SELECT "Ram" FROM Employee;

SELECT NAME FROM Employee;

How to Change the Name of the Output Title

The AS keyword can be used to provide an alias for a column in the
output.

Example

Question: Select the name and salary of all employees who are
getting more than 30000.

SELECT NAME, SAL AS 'SAL MORE THAN 30000'
FROM Employee
WHERE SAL > 30000;

How to Change the Name of Multiple Column Output Titles

The AS keyword can be used to assign aliases to multiple columns.

Example

Question: Select the name and salary of all employees who are
getting more than 30000.

SELECT NAME AS 'EMPLOYEENAME',
       SAL AS 'EMPSAL'
FROM Employee
WHERE SAL > 30000;
