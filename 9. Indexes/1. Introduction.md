# SQL INDEX

## Definition

Creating an `INDEX` statement in SQL is used to create indexes in tables.

Indexes are used to retrieve data from the database more quickly than without an index. Users generally do not directly see the index data; indexes are internal structures used to speed up queries and searches.

### Important Notes

- 🔸 Indexes speed up `SELECT` queries on large tables.
- 🔸 Indexes can slow down `INSERT`, `UPDATE`, and `DELETE` operations because the index also needs to be updated.
- 🔸 You cannot directly see the index data, but you can verify indexes using `SHOW INDEX`.

---

## Practical

### 🏗️ Step 1: Create Database and Use It

```sql
CREATE DATABASE College;
USE College;
```

### 📋 Step 2: Create Table

```sql
CREATE TABLE EMP_INFO (
    ID INT PRIMARY KEY,
    NAME VARCHAR(50),
    DEPT VARCHAR(50),
    SALARY INT
);
```

### ➕ Step 3: Insert Sample Data

```sql
INSERT INTO EMP_INFO VALUES
(101, 'Ravi', 'HR', 6000),
(102, 'Anita', 'IT', 9000),
(103, 'Suman', 'Finance', 8500),
(104, 'John', 'IT', 7500),
(105, 'Priya', 'HR', 9500);
```

View the table data:

```sql
SELECT * FROM EMP_INFO;
```

---

## ⚙️ Step 4: Create an Index on `SALARY`

### Create Index Syntax

```sql
CREATE INDEX <Index_Name> ON <Table_Name> (<Column_Name>);
```

### Example

```sql
CREATE INDEX salary_index ON EMP_INFO (SALARY ASC);
```

✅ This index can help optimize queries that filter or sort using `SALARY`.

---

## 🔍 Step 5: Run an Indexed Query

```sql
SELECT * FROM EMP_INFO
WHERE SALARY > 8000;
```

This query can benefit from the `salary_index` when the database optimizer chooses to use it.

> **Note:** Creating an index does not guarantee that the database will use it for every query. The query optimizer decides whether using the index is beneficial.

---

## 🔏 Step 6: Create a UNIQUE INDEX

Suppose `NAME` should contain unique values:

```sql
CREATE UNIQUE INDEX idx_unique_name ON EMP_INFO(NAME);
```

🛑 After creating this unique index, duplicate values in `NAME` are not allowed.

### ❌ Try to Insert a Duplicate `NAME`

```sql
-- This will fail because 'Ravi' already exists.
INSERT INTO EMP_INFO VALUES (106, 'Ravi', 'Finance', 8500);
```

> **Note:** The original example used `ID = 103`, which would also violate the primary-key constraint because `103` already exists. Using a new ID such as `106` demonstrates the unique-index violation specifically.

---

## 🏗️ Alternative: Add an INDEX While Creating a Table

An index can also be defined as part of the `CREATE TABLE` statement:

```sql
CREATE TABLE DEPT (
    ID INT,
    NAME VARCHAR(50),
    INDEX idx_dept_name(NAME)
);
```

---

## 📖 Step 7: View All Indexes on a Table

```sql
SHOW INDEX FROM EMP_INFO;
```

This displays information about the indexes defined on `EMP_INFO`.

---

## ❌ Step 8: Drop an Index

To remove the `salary_index`:

```sql
DROP INDEX salary_index ON EMP_INFO;
```

To remove the unique index:

```sql
DROP INDEX idx_unique_name ON EMP_INFO;
```
