# MySQL Stored Procedures — OUT Parameter

## What is an OUT Parameter?

An **OUT parameter** in MySQL is used to **return a value from a stored procedure to the caller**.

Unlike an `IN` parameter, which passes a value **into** the procedure, an `OUT` parameter sends a value **out of** the procedure.

### Important Points

* `OUT` parameters are used to return values from a procedure.
* The procedure can **set or modify** the value of an `OUT` parameter.
* An `OUT` parameter does **not need to be initialized** before calling the procedure.
* The procedure assigns the value to the `OUT` parameter.
* The returned value is available to the caller after the procedure finishes.
* A procedure can have **multiple OUT parameters** to return multiple values.

---

# 1. Syntax of OUT Parameter

```sql
CREATE PROCEDURE procedure_name(OUT parameter_name datatype)
BEGIN
    SQL statements;
END;
```

---

# 2. Example: Get Total Number of Employees

```sql
DELIMITER $$

CREATE PROCEDURE get_total_employees(OUT total INT)
BEGIN
    SELECT COUNT(*) INTO total
    FROM EMP_INFO;
END $$

DELIMITER ;
```

### What does this procedure do?

```text
get_total_employees → Procedure name
OUT total INT       → OUT parameter
COUNT(*)            → Counts the number of employees
INTO total          → Stores the count in the OUT parameter
```

The important statement is:

```sql
SELECT COUNT(*) INTO total
FROM EMP_INFO;
```

It counts the rows in `EMP_INFO` and stores the result in `total`.

---

# 3. How to Call an OUT Parameter Procedure

When calling a procedure with an `OUT` parameter, we can use a MySQL **session variable**.

```sql
CALL get_total_employees(@emp_count);
```

Here:

```text
@emp_count → Session variable used to receive the OUT value
```

The procedure calculates the employee count and stores the result in `@emp_count`.

---

# 4. Get the OUT Parameter Result

After calling the procedure, use `SELECT` to view the value:

```sql
SELECT @emp_count AS Total_Employees;
```

### Sample Output

| Total_Employees |
| --------------: |
|               3 |

The output depends on the number of records currently present in the `EMP_INFO` table.

# 5. Complete Example

### Step 1: Create Procedure

```sql
DELIMITER $$

CREATE PROCEDURE get_total_employees(OUT total INT)
BEGIN
    SELECT COUNT(*) INTO total
    FROM EMP_INFO;
END $$

DELIMITER ;
```

### Step 2: Call Procedure

```sql
CALL get_total_employees(@emp_count);
```

### Step 3: Display Result

```sql
SELECT @emp_count AS Total_Employees;
```

---

# 6. Example with Multiple OUT Parameters

A procedure can have more than one `OUT` parameter.

For example, we can return the **total number of employees** and the **total salary**:

```sql
DELIMITER $$

CREATE PROCEDURE get_employee_details(
    OUT total_employees INT,
    OUT total_salary INT
)
BEGIN
    SELECT COUNT(*) INTO total_employees
    FROM EMP_INFO;

    SELECT SUM(SALARY) INTO total_salary
    FROM EMP_INFO;
END $$

DELIMITER ;
```

### Call the Procedure

```sql
CALL get_employee_details(@emp_count, @total_sal);
```

### Display the Results

```sql
SELECT 
    @emp_count AS Total_Employees,
    @total_sal AS Total_Salary;
```

---

# 7. IN vs OUT

| Parameter | Purpose                                   | Can Procedure Modify It? |
| --------- | ----------------------------------------- | ------------------------ |
| `IN`      | Passes value **into** procedure           | No                       |
| `OUT`     | Returns value **from** procedure          | Yes                      |
| `INOUT`   | Passes value in and returns updated value | Yes                      |
