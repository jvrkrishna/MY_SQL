# MySQL Stored Procedures — INOUT Parameter

## What is an INOUT Parameter?

In MySQL, an `INOUT` parameter is used when a stored procedure needs to **receive a value and then return an updated value**.

It works as both **input and output**.

### Difference Between IN, OUT, and INOUT

| Parameter | Purpose                                                              |
| --------- | -------------------------------------------------------------------- |
| `IN`      | Passes data **into** the procedure                                   |
| `OUT`     | Returns data **from** the procedure                                  |
| `INOUT`   | Passes data **into** the procedure and returns the **updated value** |

### How INOUT Works

```text
Input → Procedure → Modified Value → Output
```

The value is passed when the procedure is called. The procedure can modify that value, and the updated value is available outside the procedure after execution.

---

# 1. Stored Procedure with IN and OUT Parameters

### Use Case

Pass a minimum salary and get the number of employees earning **more than** that salary.

```sql
DELIMITER $$

CREATE PROCEDURE get_emp_count_above_salary(
    IN min_sal INT,
    OUT emp_count INT
)
BEGIN
    SELECT COUNT(*)
    INTO emp_count
    FROM EMP_INFO
    WHERE SALARY > min_sal;
END $$

DELIMITER ;
```

### How It Works

```text
min_sal   → IN parameter → Receives the minimum salary
emp_count → OUT parameter → Returns the employee count
```

### Call the Procedure

```sql
CALL get_emp_count_above_salary(8500, @total);
```

Here:

```text
8500    → Value passed to min_sal
@total  → Session variable that receives emp_count
```

### Display the Result

```sql
SELECT @total AS Count_Above_8500;
```

### Sample Result

For the given data:

```text
Count_Above_8500
1
```

Only Anita has a salary greater than `8500`.

# 2. Stored Procedure with INOUT Parameter

### Use Case

Pass a salary value into the procedure and increase it by **10%**.

```sql
DELIMITER $$

CREATE PROCEDURE increase_salary_by_10(
    INOUT input_salary INT
)
BEGIN
    SET input_salary = input_salary + (input_salary * 0.10);
END $$

DELIMITER ;
```

### How It Works

The parameter:

```text
input_salary
```

acts as both:

```text
Input  → Receives the original salary
Output → Returns the updated salary
```

---

## Call the Procedure

First, create a session variable:

```sql
SET @mysalary = 8000;
```

Then pass it to the procedure:

```sql
CALL increase_salary_by_10(@mysalary);
```

Now display the updated value:

```sql
SELECT @mysalary AS New_Salary;
```

### Result

```text
New_Salary
8800
```

### Calculation

```text
8000 + (8000 × 10 / 100)
= 8000 + 800
= 8800
```

# 3. Stored Procedure with Multiple IN Parameters

A procedure can have multiple `IN` parameters.

### Use Case

Pass an address/department and minimum salary to filter employee records.

```sql
DELIMITER $$

CREATE PROCEDURE get_emps_by_dept_salary(
    IN dept_name VARCHAR(50),
    IN min_sal INT
)
BEGIN
    SELECT *
    FROM EMP_INFO
    WHERE ADDRESS = dept_name
      AND SALARY >= min_sal;
END $$

DELIMITER ;
```

### Call the Procedure

```sql
CALL get_emps_by_dept_salary('Delhi', 8000);
```

This returns employees who satisfy both conditions:

```text
ADDRESS = 'Delhi'
AND
SALARY >= 8000
```

### Sample Result

| ID | NAME  | SALARY | ADDRESS |
| -- | ----- | ------ | ------- |
| 2  | Anita | 9000   | Delhi   |
