# MySQL Stored Procedures — IN Parameter

## What is an IN Parameter?

The **IN parameter** is used to pass data **into** a stored procedure.

It is mainly used when you want to provide a value to a procedure and use that value in:

* Queries
* Conditions
* Calculations
* Filtering data

### Important Points

* `IN` parameters are **read-only** inside the procedure.
* You can use the value passed to the procedure, but you should not modify the `IN` parameter inside the procedure.
* If you do not specify `IN`, `OUT`, or `INOUT`, MySQL treats the parameter as **IN** by default.
* The value is passed **into** the procedure when calling it.

---

# 1. Syntax of IN Parameter

```sql
CREATE PROCEDURE procedure_name(IN parameter_name datatype)
BEGIN
    SQL statements;
END;
```

Example:

```sql
CREATE PROCEDURE get_Stu_by_salary(IN min_salary INT)
BEGIN
    SELECT * 
    FROM EMP_INFO
    WHERE SALARY >= min_salary;
END;
```

Here:

* `IN` → parameter direction
* `min_salary` → parameter name
* `INT` → parameter data type

---

# 2. Create Procedure with an IN Parameter

```sql
DELIMITER $$

CREATE PROCEDURE get_Stu_by_salary(IN min_salary INT)
BEGIN
    SELECT * 
    FROM EMP_INFO
    WHERE SALARY >= min_salary;
END $$

DELIMITER ;
```

The procedure accepts a salary value and returns employees whose salary is greater than or equal to that value.

---

# 3. Execute the Procedure

Call the procedure by passing a value:

```sql
CALL get_Stu_by_salary(8500);
```

Here:

```text
8500 → value passed to min_salary
```

The query becomes logically:

```sql
SELECT *
FROM EMP_INFO
WHERE SALARY >= 8500;
```

### Result

From our sample data:

| ID | NAME  | SALARY | ADDRESS |
| -- | ----- | ------ | ------- |
| 2  | Anita | 9000   | Delhi   |
| 3  | Suman | 8500   | Mumbai  |

Both employees have a salary **greater than or equal to 8500**.

---

# 4. Another Example

Suppose we want to find employees from a particular city.

```sql
DELIMITER $$

CREATE PROCEDURE get_Stu_by_address(IN city_name VARCHAR(100))
BEGIN
    SELECT *
    FROM EMP_INFO
    WHERE ADDRESS = city_name;
END $$

DELIMITER ;
```

Call the procedure:

```sql
CALL get_Stu_by_address('Delhi');
```

This returns employees whose address is `Delhi`.

---

# 5. Drop the Procedures

To remove the procedures:

```sql
DROP PROCEDURE IF EXISTS get_Stu_info;

DROP PROCEDURE IF EXISTS get_Stu_by_salary;

DROP PROCEDURE IF EXISTS get_Stu_by_address;
```
