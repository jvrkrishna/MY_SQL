## Introduction to DDL

**DDL** stands for **Data Definition Language**.

DDL is a subset of **SQL (Structured Query Language)**.

The main purpose of DDL is to **create, modify, and delete database objects**.

DDL is used to define and manage the structure of database objects such as:

- Databases
- Tables
- Views
- Procedures
- Functions
- Triggers
- etc.

### Common DDL Commands

| Command | Purpose |
|---|---|
| `CREATE` | To create a new database object, such as a database or table |
| `ALTER` | To modify an existing database object |
| `DROP` | To permanently delete a database object |
| `TRUNCATE` | To remove all rows from a table while keeping its structure |
| `RENAME` | To rename a database object |
