# RENAME Command in MySQL

The `RENAME` command is used to **change the name of database objects**, such as tables and columns.

In MySQL, table and column renaming is commonly done using `RENAME` or `ALTER TABLE`.

The `RENAME` command can be used to:

* Rename a table
* Rename multiple tables
* Rename a column

---

# 1. Rename a Table

A table can be renamed using the `RENAME TABLE` command.

## Syntax

```sql id="pld5am"
RENAME TABLE old_table_name TO new_table_name;
```

## Example

```sql id="3gn0td"
RENAME TABLE employee TO staff;
```

This changes the table name from `employee` to `staff`.

---

# 2. Rename a Table Using ALTER TABLE

We can also rename a table using `ALTER TABLE`.

## Syntax

```sql id="jq8v7q"
ALTER TABLE old_table_name
RENAME TO new_table_name;
```

## Example

```sql id="zjtx1v"
ALTER TABLE employee
RENAME TO staff;
```

This renames the table `employee` to `staff`.

### RENAME TABLE vs ALTER TABLE

Both of the following commands can rename a table in MySQL:

```sql id="f8h0tj"
RENAME TABLE employee TO staff;
```

```sql id="c3v90m"
ALTER TABLE employee
RENAME TO staff;
```

---

# 3. Rename Multiple Tables

MySQL allows us to rename multiple tables using a **single `RENAME TABLE` statement**.

## Syntax

```sql id="yrh9eh"
RENAME TABLE
    old_table1 TO new_table1,
    old_table2 TO new_table2,
    old_table3 TO new_table3;
```

## Example

```sql id="xy3r8q"
RENAME TABLE
    employee TO staff,
    department TO departments,
    student TO students;
```

All three tables are renamed in one statement.

---

# 4. Rename a Column

To rename a column in MySQL, we can use `ALTER TABLE` with `RENAME COLUMN`.

## Syntax

```sql id="c4q8qp"
ALTER TABLE table_name
RENAME COLUMN old_column_name TO new_column_name;
```

## Example

```sql id="e9u0p5"
ALTER TABLE employee
RENAME COLUMN NAME TO full_name;
```

This changes the column name from `NAME` to `full_name`.

---

# 5. Rename Multiple Columns

MySQL does **not** support renaming multiple columns using multiple `RENAME COLUMN` clauses in a single `ALTER TABLE` statement.

Therefore, rename the columns **one by one**.

## Example

### Rename the first column

```sql id="qf1f5s"
ALTER TABLE employee
RENAME COLUMN NAME TO full_name;
```

### Rename the second column

```sql id="s9g2fa"
ALTER TABLE employee
RENAME COLUMN ADDRESS TO location;
```

Now:

```text id="8f0rgl"
NAME     → full_name
ADDRESS  → location
```

# 6. Practical Example

## Create a Database

```sql id="8q3v5j"
CREATE DATABASE COLLEGE;
```

## Select the Database

```sql id="3sgv8q"

```

## Create Tables

```sql id="n7zv5q"
CREATE TABLE employee (
    ID INT,

    ADDRESS VARCHAR(50)
);

    ID INT,
    DEPT_NAME VARCHAR(30)
);
```

## Show Tables

```sql id="g8y3rj"

```

```sql id="b4zj8x"

```


View the table structure:

```sql id="qj7f9s"

RENAME COLUMN ADDRESS TO location;
```


# Complete Practical Example

```sql id="v0p2c6"
-- Create database
CREATE DATABASE COLLEGE;

-- Select database
USE COLLEGE;

-- Create employee table
CREATE TABLE employee (
    ID INT,
    NAME VARCHAR(30),
    ADDRESS VARCHAR(50)
);

    ID INT,
    DEPT_NAME VARCHAR(30)

SHOW TABLES;

-- Rename employee table
RENAME TABLE employee TO staff;

-- Show tables again
SHOW TABLES;

-- Rename NAME column
ALTER TABLE staff
RENAME COLUMN NAME TO full_name;

-- Rename ADDRESS column
ALTER TABLE staff
RENAME COLUMN ADDRESS TO location;

-- View table structure
DESC staff;
```

---

# Important Points

* `RENAME TABLE` can be used to rename a table.
* `ALTER TABLE ... RENAME TO` can also be used to rename a table.
* MySQL allows multiple tables to be renamed in one `RENAME TABLE` statement.
* `ALTER TABLE ... RENAME COLUMN` is used to rename a column.
* Multiple columns should be renamed using separate `ALTER TABLE ... RENAME COLUMN` statements.
* Renaming a table or column changes its name; it does not normally remove the data stored in it.
