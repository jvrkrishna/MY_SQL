# MySQL ALTER TABLE 

> **Basic pattern:** `CREATE DATABASE` → `USE` →
> `CREATE TABLE` → `INSERT` → `SELECT *` → `ALTER TABLE` → `DESC` /
> `SHOW CREATE TABLE` → `SELECT *`.

------------------------------------------------------------------------

# 1. Adding a New Column

The `ALTER TABLE ... ADD` command adds a new column to an existing
table.

## Syntax

``` sql
ALTER TABLE table_name
ADD column_name datatype(size);
```

## Complete Example

``` sql
CREATE DATABASE alter_add_column_db;

USE alter_add_column_db;

CREATE TABLE student (
    Roll_No INT,
    Name VARCHAR(30),
    Course VARCHAR(30)
);

INSERT INTO student VALUES
(1, 'Ravi', 'BCA'),
(2, 'Anjali', 'BCA'),
(3, 'Kiran', 'MCA');

SELECT * FROM student;

DESC student;

ALTER TABLE student
ADD Address VARCHAR(50);

DESC student;

SELECT * FROM student;

UPDATE student
SET Address = 'Kakinada'
WHERE Roll_No = 1;

UPDATE student
SET Address = 'Rajahmundry'
WHERE Roll_No = 2;

UPDATE student
SET Address = 'Vijayawada'
WHERE Roll_No = 3;

SELECT * FROM student;
```

### What students learn

Before `ALTER`:

``` text
Roll_No | Name | Course
```

After `ALTER`:

``` text
Roll_No | Name | Course | Address
```

We can add more than one column to an existing table.


# 3. Deleting an Existing Column

The `DROP COLUMN` command permanently removes a column and its data.

## Syntax

``` sql
ALTER TABLE table_name
DROP COLUMN column_name;
```

## Complete Example

``` sql
CREATE DATABASE alter_drop_column_db;

USE alter_drop_column_db;

CREATE TABLE student (
    Roll_No INT,
    Name VARCHAR(30),
    Course VARCHAR(30),
    Address VARCHAR(50),
    Marks INT
);

INSERT INTO student VALUES
(1, 'Ravi', 'BCA', 'Kakinada', 85),
(2, 'Anjali', 'BCA', 'Hyderabad', 92),
(3, 'Kiran', 'MCA', 'Vijayawada', 78);

SELECT * FROM student;

DESC student;

ALTER TABLE student
DROP COLUMN Address;

DESC student;

SELECT * FROM student;
```

> **Important:** Dropping a column also removes the data stored in that
> column.

# 9. NOT NULL Constraint

The `NOT NULL` constraint prevents a column from containing `NULL`.

## Complete Example

``` sql
CREATE DATABASE alter_not_null_db;

USE alter_not_null_db;

CREATE TABLE employee (
    ID INT,
    Name VARCHAR(30),
    Address VARCHAR(50)
);

INSERT INTO employee VALUES
(1, 'Ravi', 'Kakinada'),
(2, 'Anjali', 'Hyderabad'),
(3, NULL, 'Vijayawada');

SELECT * FROM employee;

SELECT *
FROM employee
WHERE Name IS NULL;

UPDATE employee
SET Name = 'Unknown'
WHERE Name IS NULL;

ALTER TABLE employee
MODIFY Name VARCHAR(30) NOT NULL;

DESC employee;

SELECT * FROM employee;
```

## Test NOT NULL

``` sql
INSERT INTO employee(ID, Name, Address)
VALUES (4, NULL, 'Rajahmundry');
```

This should fail because `Name` is `NOT NULL`.

> **Important:** Before adding `NOT NULL`, check and correct existing
> `NULL` values.

# 10. UNIQUE Constraint

The `UNIQUE` constraint prevents duplicate values.

## Complete Example

``` sql
CREATE DATABASE alter_unique_db;

USE alter_unique_db;

CREATE TABLE employee (
    ID INT,
    Name VARCHAR(30),
    Mobile VARCHAR(15)
);

INSERT INTO employee VALUES
(1, 'Ravi', '9876543210'),
(2, 'Anjali', '9876543211'),
(3, 'Kiran', '9876543212');

SELECT * FROM employee;

ALTER TABLE employee
ADD CONSTRAINT unique_mobile
UNIQUE (Mobile);

SHOW CREATE TABLE employee;
```

## Test UNIQUE Constraint

This should work:

``` sql
INSERT INTO employee
VALUES (4, 'Suresh', '9876543213');
```

This should fail:

``` sql
INSERT INTO employee
VALUES (5, 'Ramesh', '9876543210');
```

The second statement fails because `9876543210` already exists.

## Check Existing Duplicates

Before adding `UNIQUE`, students can check for duplicates:

``` sql
SELECT Mobile, COUNT(*)
FROM employee
GROUP BY Mobile
HAVING COUNT(*) > 1;
```

# 11. PRIMARY KEY Constraint

A primary key uniquely identifies each row.

A primary key:

-   Must be unique.
-   Cannot contain `NULL`.
-   A table can have only one primary key constraint.
-   A primary key can contain one or more columns.

## Complete Example

``` sql
CREATE DATABASE alter_primary_key_db;

USE alter_primary_key_db;

CREATE TABLE student (
    Roll_No INT,
    Name VARCHAR(30),
    Course VARCHAR(30)
);

INSERT INTO student VALUES
(1, 'Ravi', 'BCA'),
(2, 'Anjali', 'MCA'),
(3, 'Kiran', 'BSc');

SELECT * FROM student;

DESC student;

ALTER TABLE student
ADD CONSTRAINT pk_student
PRIMARY KEY (Roll_No);

DESC student;

SHOW CREATE TABLE student;
```

## Test Duplicate Primary Key

``` sql
INSERT INTO student
VALUES (1, 'Suresh', 'BCom');
```

This fails because `Roll_No = 1` already exists.

## Test NULL Primary Key

``` sql
INSERT INTO student
VALUES (NULL, 'Ramesh', 'BCA');
```

This fails because a primary key cannot be `NULL`.

# 12. Composite PRIMARY KEY

A composite primary key contains more than one column.

## Complete Example

``` sql
CREATE DATABASE alter_composite_pk_db;

USE alter_composite_pk_db;

CREATE TABLE enrollment (
    Student_ID INT,
    Course_ID INT,
    Student_Name VARCHAR(30)
);

INSERT INTO enrollment VALUES
(1, 101, 'Ravi'),
(1, 102, 'Ravi'),
(2, 101, 'Anjali');

SELECT * FROM enrollment;

ALTER TABLE enrollment
ADD CONSTRAINT pk_enrollment
PRIMARY KEY (Student_ID, Course_ID);

DESC enrollment;

SHOW CREATE TABLE enrollment;
```

Here:

``` text
Student_ID + Course_ID
```

together form the primary key.

The same `Student_ID` can appear more than once as long as the
combination is different.

# 13. Dropping PRIMARY KEY

The `DROP PRIMARY KEY` command removes the primary key constraint but
does not delete the column.

## Complete Example

``` sql
CREATE DATABASE alter_drop_pk_db;

USE alter_drop_pk_db;

CREATE TABLE student (
    Roll_No INT PRIMARY KEY,
    Name VARCHAR(30),
    Course VARCHAR(30)
);

INSERT INTO student VALUES
(1, 'Ravi', 'BCA'),
(2, 'Anjali', 'MCA'),
(3, 'Kiran', 'BSc');

SELECT * FROM student;

ALTER TABLE student
DROP PRIMARY KEY;

DESC student;

SHOW CREATE TABLE student;

```

### Teaching point

Only the primary key constraint is removed.

The `Roll_No` column remains in the table.

# 14. FOREIGN KEY Constraint

A foreign key creates a relationship between two tables.

-   Parent table = table containing the referenced key.
-   Child table = table containing the foreign key.

## Complete Example

``` sql
CREATE DATABASE alter_foreign_key_db;

USE alter_foreign_key_db;

-- Parent table
CREATE TABLE department (
    Dept_ID INT,
    Dept_Name VARCHAR(30)
);

-- Child table
CREATE TABLE employee (
    Emp_ID INT,
    Emp_Name VARCHAR(30),
    Dept_ID INT
);

-- Insert parent data
INSERT INTO department VALUES
(1, 'HR'),
(2, 'Developer'),
(3, 'Testing');

SELECT * FROM department;

-- Insert child data
INSERT INTO employee VALUES
(101, 'Ravi', 1),
(102, 'Anjali', 2),
(103, 'Kiran', 3);

SELECT * FROM employee;

-- Add primary key to parent
ALTER TABLE department
ADD PRIMARY KEY (Dept_ID);

-- Add foreign key to child
ALTER TABLE employee
ADD CONSTRAINT fk_employee_department
FOREIGN KEY (Dept_ID)
REFERENCES department(Dept_ID);

SHOW CREATE TABLE department;

SHOW CREATE TABLE employee;
```

## Test Valid Foreign Key

This should work:

``` sql
INSERT INTO employee
VALUES (104, 'Suresh', 2);
```

Department `2` exists.

## Test Invalid Foreign Key

This should fail:

``` sql
INSERT INTO employee
VALUES (105, 'Ramesh', 10);
```

Department `10` does not exist.

## Display Final Data

``` sql
SELECT * FROM department;

SELECT * FROM employee;
```

# 16. CHECK Constraint

The `CHECK` constraint ensures that values satisfy a condition.

> **MySQL note:** Modern MySQL versions enforce `CHECK` constraints. For
> classroom demonstrations, use a current MySQL version.

## Complete Example

``` sql
CREATE DATABASE alter_check_db;

USE alter_check_db;

CREATE TABLE employee (
    ID INT,
    Name VARCHAR(30),
    Age INT
);

INSERT INTO employee VALUES
(1, 'Ravi', 25),
(2, 'Anjali', 22),
(3, 'Kiran', 30);

SELECT * FROM employee;

ALTER TABLE employee
ADD CONSTRAINT chk_employee_age
CHECK (Age >= 18);

DESC employee;

SHOW CREATE TABLE employee;
```

## Test Valid Data

``` sql
INSERT INTO employee
VALUES (4, 'Suresh', 21);
```

## Test Invalid Data

``` sql
INSERT INTO employee
VALUES (5, 'Ramesh', 15);
```

The second statement should fail because:

``` text
15 < 18
```

# 17. DEFAULT Constraint

A `DEFAULT` value is automatically used when a value is not supplied
during `INSERT`.

## Complete Example

``` sql
CREATE DATABASE alter_default_db;

USE alter_default_db;

CREATE TABLE employee (
    ID INT,
    Name VARCHAR(30),
    City VARCHAR(30)
);

INSERT INTO employee VALUES
(1, 'Ravi', 'Kakinada'),
(2, 'Anjali', 'Hyderabad'),
(3, 'Kiran', 'Vijayawada');

SELECT * FROM employee;

ALTER TABLE employee
MODIFY City VARCHAR(30) DEFAULT 'Kakinada';

DESC employee;

INSERT INTO employee(ID, Name)
VALUES (4, 'Suresh');

SELECT * FROM employee;
```

The fourth employee receives:

``` text
City = Kakinada
```

because `City` was not supplied.

# 19. Adding NOT NULL, UNIQUE, PRIMARY KEY, CHECK and DEFAULT Together

This example is useful as a final demonstration of multiple constraints.

``` sql
CREATE DATABASE alter_constraints_db;

USE alter_constraints_db;

CREATE TABLE student (
    Roll_No INT,
    Name VARCHAR(50),
    Email VARCHAR(100),
    Age INT,
    City VARCHAR(30)
);

INSERT INTO student VALUES
(1, 'Ravi', 'ravi@gmail.com', 20, 'Kakinada'),
(2, 'Anjali', 'anjali@gmail.com', 21, 'Hyderabad'),
(3, 'Kiran', 'kiran@gmail.com', 19, 'Vijayawada');

SELECT * FROM student;

DESC student;

-- PRIMARY KEY
ALTER TABLE student
ADD CONSTRAINT pk_student
PRIMARY KEY (Roll_No);

-- NOT NULL
ALTER TABLE student
MODIFY Name VARCHAR(50) NOT NULL;

-- UNIQUE
ALTER TABLE student
ADD CONSTRAINT unique_email
UNIQUE (Email);

-- CHECK
ALTER TABLE student
ADD CONSTRAINT chk_student_age
CHECK (Age >= 18);

ALTER TABLE student
MODIFY City VARCHAR(30) DEFAULT 'Kakinada';

DESC student;

SHOW CREATE TABLE student;

```

# 22. DELETE vs TRUNCATE vs DROP

These commands are different from `ALTER TABLE`.

  Command         Purpose
  --------------- --------------------------------------------
  `DELETE`        Removes rows
  `TRUNCATE`      Removes all rows but keeps table structure
  `DROP TABLE`    Removes the table itself
  `ALTER TABLE`   Changes table structure

## DELETE Example

``` sql
CREATE DATABASE delete_truncate_drop_db;

USE delete_truncate_drop_db;

CREATE TABLE student (
    Roll_No INT,
    Name VARCHAR(30)
);

INSERT INTO student VALUES
(1, 'Ravi'),
(2, 'Anjali'),
(3, 'Kiran');

SELECT * FROM student;

DELETE FROM student
WHERE Roll_No = 2;

SELECT * FROM student;
```

Only the matching row is removed.

## TRUNCATE Example

``` sql
TRUNCATE TABLE student;

SELECT * FROM student;

DESC student;
```

All rows are removed, but the table still exists.

## DROP Example

``` sql
DROP TABLE student;
```

The table itself is removed.

Trying:

``` sql
SELECT * FROM student;
```

after `DROP TABLE` produces an error because the table no longer exists.



If you don't want to use SHOW DATABASES; and you don't know the database names, you can generate and execute the DROP DATABASE statements directly using MySQL's information_schema.

``` sql
CREATE DATABASE IF NOT EXISTS temp_cleanup_db;
USE temp_cleanup_db;

DELIMITER //

CREATE PROCEDURE drop_all_user_databases()
BEGIN
    DECLARE done INT DEFAULT 0;
    DECLARE db_name VARCHAR(255);

    DECLARE db_cursor CURSOR FOR
        SELECT SCHEMA_NAME
        FROM information_schema.SCHEMATA
        WHERE SCHEMA_NAME NOT IN
        ('information_schema', 'mysql', 'performance_schema', 'sys', 'temp_cleanup_db');

    DECLARE CONTINUE HANDLER FOR NOT FOUND SET done = 1;

    OPEN db_cursor;

    read_loop: LOOP
        FETCH db_cursor INTO db_name;

        IF done THEN
            LEAVE read_loop;
        END IF;

        SET @sql = CONCAT('DROP DATABASE IF EXISTS `', REPLACE(db_name, '`', '``'), '`');

        PREPARE stmt FROM @sql;
        EXECUTE stmt;
        DEALLOCATE PREPARE stmt;
    END LOOP;

    CLOSE db_cursor;
END//

DELIMITER ;

CALL drop_all_user_databases();

DROP PROCEDURE drop_all_user_databases;
DROP DATABASE temp_cleanup_db;


show databases;
```
