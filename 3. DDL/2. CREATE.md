# CREATE Command in SQL

## What is CREATE Command?

The `CREATE` command is a **DDL (Data Definition Language)** command.

It is used to create database objects such as:

* Databases
* Tables
* Views
* Procedures
* Functions
* Triggers

---

## Creating a Database

### Create a Database

```sql
CREATE DATABASE COLLEGE;
```

This creates a database named `COLLEGE`.

### Show All Databases

```sql
SHOW DATABASES;
```

This command displays all the databases available in the MySQL server.

### Delete a Database

The `DROP DATABASE` command is used to delete a database.

```sql
DROP DATABASE COLLEGE;
```

### Show Databases Again

```sql
SHOW DATABASES;
```

After deleting the `COLLEGE` database, it will no longer appear in the list.

# What is a Table?

A **table** is a collection of **rows and columns**.

In a relational database, a table is also called a **relation**.

### Column

A column represents a particular type of information.

A column is also known as:

* Field
* Attribute

### Row

A row represents one complete record in a table.

A row is also known as:

* Record
* Tuple

### Example

| Roll | Name | Course | Mark | Gender |
| ---: | ---- | ------ | ---: | ------ |
|  101 | Ravi | Java   |   85 | M      |
|  102 | Sita | Python |   90 | F      |

In the above table:

* `Roll`, `Name`, `Course`, `Mark`, and `Gender` are **columns**.
* Each student's information is a **row/record**.
* The complete table is a **relation**.

> **Note:** An **instance** generally refers to the data stored in a database at a particular point in time.

---

# How to Create a Table

## Syntax

```sql
CREATE TABLE table_name (
    column1 datatype(size),
    column2 datatype(size),
    ...
    columnN datatype(size)
);
```

### Explanation

* `CREATE TABLE` → Used to create a new table.
* `table_name` → Name of the table.
* `column1, column2, ...` → Names of the columns.
* `datatype` → Specifies the type of data stored in the column.
* `size` → Specifies the maximum size where applicable.

---

# Example Question

### Question

**Write a query to create a table named `stud_info` with 5 columns: `roll`, `name`, `course`, `mark`, and `gender`.**

### Answer

```sql
CREATE TABLE stud_info (
    Roll INT,
    Name VARCHAR(30),
    Course VARCHAR(20),
    Mark INT,
    Gender CHAR
);
```

### Explanation

| Column   | Data Type     | Purpose                                |
| -------- | ------------- | -------------------------------------- |
| `Roll`   | `INT`         | Stores integer values                  |
| `Name`   | `VARCHAR(30)` | Stores name up to 30 characters        |
| `Course` | `VARCHAR(20)` | Stores course name up to 20 characters |
| `Mark`   | `INT`         | Stores integer marks                   |
| `Gender` | `CHAR`        | Stores a character value               |

# Practical Example

## Step 1: Create the Database

```sql
CREATE DATABASE COLLEGE;
```

## Step 2: Select the Database

The `USE` command is used to select a database for working with it.

```sql
USE COLLEGE;
```

## Step 3: Create the Table

```sql
CREATE TABLE stud_info (
    Roll INT,
    Name VARCHAR(30),
    Course VARCHAR(20),
    Mark INT,
    Gender CHAR
);
```

## Step 4: Show All Databases

```sql
SHOW DATABASES;
```

## Step 5: View the Table Data

```sql
SELECT * FROM stud_info;
```

Since no records have been inserted yet, the table will be empty.

# Complete Practical Example

```sql
-- Create the database
CREATE DATABASE COLLEGE;

-- Select the database
USE COLLEGE;

-- Create the table
CREATE TABLE stud_info (
    Roll INT,
    Name VARCHAR(30),
    Course VARCHAR(20),
    Mark INT,
    Gender CHAR
);

-- Show all databases
SHOW DATABASES;

-- View the table data
SELECT * FROM stud_info;
```
