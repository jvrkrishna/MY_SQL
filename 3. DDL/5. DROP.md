# DROP Command in MySQL

The `DROP` command is a **DDL (Data Definition Language)** command.

It is used to **permanently remove a database object** from the database.

When a database object is dropped, the object and its associated data are removed.

## Common Uses of DROP

We can use the `DROP` command to remove:

* Tables
* Databases
* Views
* Indexes

---

# 1. DROP TABLE

`DROP TABLE` is used to permanently remove a table from a database.

### Syntax

```sql
DROP TABLE table_name;
```

### Example

```sql
DROP TABLE stud_info;
```

This removes the `stud_info` table and all the data stored in it.

> **Important:** After dropping a table, the table structure and its data are removed.

---

# 2. DROP DATABASE

`DROP DATABASE` is used to permanently remove a database.

### Syntax

```sql
DROP DATABASE database_name;
```

### Example

```sql
DROP DATABASE college;
```

This removes the `college` database and all the tables and data inside it.

> **Important:** `DROP DATABASE` is a destructive operation. The database and its contents are removed.

---

# 3. DROP VIEW

A **view** is a virtual table based on a query.

`DROP VIEW` is used to remove a view.

### Syntax

```sql
DROP VIEW view_name;
```

### Example

```sql
DROP VIEW student_view;
```

This removes the `student_view` view.

---

# 4. DROP INDEX

An **index** is used to improve the speed of data retrieval.

`DROP INDEX` is used to remove an index.

In MySQL, the syntax is:

```sql
DROP INDEX index_name ON table_name;
```

### Example

```sql
DROP INDEX idx_name ON student;
```

This removes the `idx_name` index from the `student` table.

---

# Practical Example

## Step 1: Show Existing Databases

```sql
SHOW DATABASES;
```

## Step 2: Create a Database

```sql
CREATE DATABASE COLLEGE;
```

## Step 3: Select the Database

```sql
USE COLLEGE;
```

## Step 4: Show Tables

```sql
SHOW TABLES;
```

## Step 5: Create a Table

```sql
CREATE TABLE stud_info (
    Roll INT,
    Name VARCHAR(30),
    Course VARCHAR(20)
);
```

## Step 6: View Table Data

```sql
SELECT * FROM stud_info;
```

Since no records have been inserted, the table will be empty.

## Step 7: Drop the Table

```sql
DROP TABLE stud_info;
```

The `stud_info` table is now permanently removed.

## Step 8: Show Tables Again

```sql
SHOW TABLES;
```

The `stud_info` table will no longer appear.

## Step 9: Drop the Database

```sql
DROP DATABASE COLLEGE;
```

The `COLLEGE` database and everything inside it are permanently removed.

---

# Complete Practical Example

```sql
-- Show databases
SHOW DATABASES;

-- Create database
CREATE DATABASE COLLEGE;

-- Select database
USE COLLEGE;

-- Show tables
SHOW TABLES;

-- Create table
CREATE TABLE stud_info (
    Roll INT,
    Name VARCHAR(30),
    Course VARCHAR(20)
);

-- View table data
SELECT * FROM stud_info;

-- Drop table
DROP TABLE stud_info;

-- Show tables again
SHOW TABLES;

-- Drop database
DROP DATABASE COLLEGE;

-- Show databases again
SHOW DATABASES;
```

> **Important:** `DROP` permanently removes the specified database object. Always make sure you are dropping the correct object before executing the command.
