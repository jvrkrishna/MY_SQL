# DROP Command in MySQL

The `DROP` command is a **DDL (Data Definition Language)** command.

It is used to **permanently remove a database object**.

Common objects that can be dropped are:

-   Tables
-   Databases
-   Views
-   Indexes
-   Primary keys and foreign keys using `ALTER TABLE`

> **Warning:** `DROP` is destructive. The specified object and its
> associated data are permanently removed.

------------------------------------------------------------------------

# 1. DROP TABLE

`DROP TABLE` permanently removes a table and all data stored in it.

## Syntax

``` sql
DROP TABLE table_name;
```

## Complete Practical Example

``` sql
CREATE DATABASE drop_table_db;

USE drop_table_db;

CREATE TABLE student (
    Roll_No INT,
    Name VARCHAR(30),
    Course VARCHAR(30)
);

INSERT INTO student VALUES
(1, 'Ravi', 'BCA'),
(2, 'Anjali', 'MCA'),
(3, 'Kiran', 'BSc');

-- View data before DROP
SELECT * FROM student;

-- View tables
SHOW TABLES;

-- Drop the table
DROP TABLE student;

-- View tables after DROP
SHOW TABLES;
```

After:

``` sql
DROP TABLE student;
```

the table no longer exists.

Trying:

``` sql
SELECT * FROM student;
```

will produce an error because the table has been removed.

## Using IF EXISTS

``` sql
DROP TABLE IF EXISTS student;
```

This prevents an error if the table does not exist.

------------------------------------------------------------------------

# 2. DROP DATABASE

`DROP DATABASE` permanently removes a database and everything inside it.

## Syntax

``` sql
DROP DATABASE database_name;
```

## Complete Practical Example

``` sql
CREATE DATABASE drop_database_db;

USE drop_database_db;

CREATE TABLE student (
    Roll_No INT,
    Name VARCHAR(30),
    Course VARCHAR(30)
);

INSERT INTO student VALUES
(1, 'Ravi', 'BCA'),
(2, 'Anjali', 'MCA'),
(3, 'Kiran', 'MCA');

SELECT * FROM student;

SHOW TABLES;

-- Drop the complete database
DROP DATABASE drop_database_db;
```

The following are removed together:

``` text
Database
    |
    +-- Tables
    |     |
    |     +-- Data
    |
    +-- Other database objects
```

## Using IF EXISTS

``` sql
DROP DATABASE IF EXISTS drop_database_db;
```

> **Warning:** `DROP DATABASE` permanently removes the database and
> everything inside it.

------------------------------------------------------------------------

# 3. DROP VIEW

A **view** is a virtual table based on a query.

`DROP VIEW` removes the view.

> Dropping a view does **not** delete the original tables used by the
> view.

## Syntax

``` sql
DROP VIEW view_name;
```

## Complete Practical Example

``` sql
CREATE DATABASE drop_view_db;

USE drop_view_db;

CREATE TABLE student (
    Roll_No INT,
    Name VARCHAR(30),
    Course VARCHAR(30),
    Marks INT
);

INSERT INTO student VALUES
(1, 'Ravi', 'BCA', 85),
(2, 'Anjali', 'MCA', 92),
(3, 'Kiran', 'BSc', 78);

SELECT * FROM student;

-- Create a view
CREATE VIEW student_view AS
SELECT Roll_No, Name, Course
FROM student;

-- Display the view
SELECT * FROM student_view;

-- Show views
SHOW FULL TABLES
WHERE TABLE_TYPE = 'VIEW';

-- Drop the view
DROP VIEW student_view;

-- Verify that the view is removed
SHOW FULL TABLES
WHERE TABLE_TYPE = 'VIEW';

-- Original table still exists
SELECT * FROM student;
```

## Using IF EXISTS

``` sql
DROP VIEW IF EXISTS student_view;
```

### Important Point

After:

``` sql
DROP VIEW student_view;
```

the original `student` table still exists.

------------------------------------------------------------------------

# 4. DROP INDEX

An index improves the speed of data retrieval.

`DROP INDEX` removes an index from a table.

## Syntax

``` sql
DROP INDEX index_name ON table_name;
```

## Complete Practical Example

``` sql
CREATE DATABASE drop_index_db;

USE drop_index_db;

CREATE TABLE student (
    Roll_No INT,
    Name VARCHAR(30),
    Course VARCHAR(30)
);

INSERT INTO student VALUES
(1, 'Ravi', 'BCA'),
(2, 'Anjali', 'MCA'),
(3, 'Kiran', 'BSc');

SELECT * FROM student;

-- Create an index
CREATE INDEX idx_student_name
ON student(Name);

-- View indexes
SHOW INDEX FROM student;

-- Drop the index
DROP INDEX idx_student_name
ON student;

-- View indexes again
SHOW INDEX FROM student;
```

### Important Point

Dropping an index does **not** delete:

-   The column
-   The table
-   The data

It only removes the index.

------------------------------------------------------------------------

# 5. DROP PRIMARY KEY

A primary key can be removed using `ALTER TABLE`.

## Syntax

``` sql
ALTER TABLE table_name
DROP PRIMARY KEY;
```

## Complete Practical Example

``` sql
CREATE DATABASE drop_primary_key_db;

USE drop_primary_key_db;

CREATE TABLE student (
    Roll_No INT PRIMARY KEY,
    Name VARCHAR(30),
    Course VARCHAR(30)
);

INSERT INTO student VALUES
(1, 'Ravi', 'BCA'),
(2, 'Anjali', 'MCA'),
(3, 'Kiran', 'BSc');

SELECT * FROM student;

SHOW CREATE TABLE student;

-- Drop the primary key
ALTER TABLE student
DROP PRIMARY KEY;

-- Check the result
DESC student;

SHOW CREATE TABLE student;

SELECT * FROM student;
```

### Important Point

The `Roll_No` column is **not deleted**.

Only the primary key constraint is removed.

------------------------------------------------------------------------

# 6. DROP FOREIGN KEY

A foreign key is removed using `ALTER TABLE`.

## Syntax

``` sql
ALTER TABLE child_table
DROP FOREIGN KEY constraint_name;
```

## Complete Practical Example

``` sql
CREATE DATABASE drop_foreign_key_db;

USE drop_foreign_key_db;

-- Parent table
CREATE TABLE department (
    Dept_ID INT PRIMARY KEY,
    Dept_Name VARCHAR(30)
);

-- Child table
CREATE TABLE employee (
    Emp_ID INT,
    Emp_Name VARCHAR(30),
    Dept_ID INT
);

INSERT INTO department VALUES
(1, 'HR'),
(2, 'Developer'),
(3, 'Testing');

INSERT INTO employee VALUES
(101, 'Ravi', 1),
(102, 'Anjali', 2),
(103, 'Kiran', 3);

-- Add foreign key
ALTER TABLE employee
ADD CONSTRAINT fk_employee_department
FOREIGN KEY (Dept_ID)
REFERENCES department(Dept_ID);

-- View foreign key
SHOW CREATE TABLE employee;

-- Drop foreign key
ALTER TABLE employee
DROP FOREIGN KEY fk_employee_department;

-- Verify
SHOW CREATE TABLE employee;

SELECT * FROM employee;
```

### Important Point

The constraint name:

``` text
fk_employee_department
```

is used when dropping the foreign key.

The `Dept_ID` column is **not deleted**.

------------------------------------------------------------------------

# 7. DROP TABLE vs DROP DATABASE vs DROP VIEW vs DROP INDEX

  Command                          What is Removed?
  -------------------------------- -------------------------------------------
  `DROP TABLE`                     Table + all its data
  `DROP DATABASE`                  Database + all objects and data inside it
  `DROP VIEW`                      View only
  `DROP INDEX`                     Index only
  `ALTER TABLE DROP PRIMARY KEY`   Primary key constraint only
  `ALTER TABLE DROP FOREIGN KEY`   Foreign key constraint only

------------------------------------------------------------------------

# 8. DROP vs DELETE vs TRUNCATE

Students should clearly understand the difference.

  Command             Removes Rows   Removes Table Structure   Removes Database
  ----------------- -------------- ------------------------- ------------------
  `DELETE`                     Yes                        No                 No
  `TRUNCATE`              All rows                        No                 No
  `DROP TABLE`                 Yes                       Yes                 No
  `DROP DATABASE`              Yes                       Yes                Yes

------------------------------------------------------------------------

## DELETE

``` sql
DELETE FROM student;
```

Removes rows but keeps the table.

### Example

``` sql
CREATE DATABASE delete_example_db;

USE delete_example_db;

CREATE TABLE student (
    Roll_No INT,
    Name VARCHAR(30)
);

INSERT INTO student VALUES
(1, 'Ravi'),
(2, 'Anjali'),
(3, 'Kiran');

SELECT * FROM student;

DELETE FROM student
WHERE Roll_No = 2;

SELECT * FROM student;
```

Only the row with `Roll_No = 2` is removed.

------------------------------------------------------------------------

# 9. TRUNCATE

`TRUNCATE TABLE` removes all rows but keeps the table structure.

## Complete Example

``` sql
CREATE DATABASE truncate_example_db;

USE truncate_example_db;

CREATE TABLE student (
    Roll_No INT,
    Name VARCHAR(30)
);

INSERT INTO student VALUES
(1, 'Ravi'),
(2, 'Anjali'),
(3, 'Kiran');

SELECT * FROM student;

TRUNCATE TABLE student;

SELECT * FROM student;

DESC student;
```

The table still exists, but it contains no rows.

------------------------------------------------------------------------

# 10. DROP TABLE vs TRUNCATE

Before:

``` text
student table
-----------------------
1   Ravi
2   Anjali
3   Kiran
```

After:

``` sql
TRUNCATE TABLE student;
```

Result:

``` text
student table
-----------------------
empty
```

The table still exists.

After:

``` sql
DROP TABLE student;
```

Result:

``` text
student table
-----------------------
does not exist
```

------------------------------------------------------------------------

# 11. Complete DROP Practical Example

This example demonstrates:

1.  Create database
2.  Create table
3.  Insert data
4.  Create index
5.  Drop index
6.  Create view
7.  Drop view
8.  Drop table
9.  Drop database

``` sql
CREATE DATABASE drop_complete_db;

USE drop_complete_db;

-- =========================================
-- STEP 1: CREATE TABLE
-- =========================================

CREATE TABLE student (
    Roll_No INT,
    Name VARCHAR(30),
    Course VARCHAR(30)
);

-- =========================================
-- STEP 2: INSERT DATA
-- =========================================

INSERT INTO student VALUES
(1, 'Ravi', 'BCA'),
(2, 'Anjali', 'MCA'),
(3, 'Kiran', 'BSc');

-- =========================================
-- STEP 3: VIEW DATA
-- =========================================

SELECT * FROM student;

-- =========================================
-- STEP 4: SHOW TABLES
-- =========================================

SHOW TABLES;

-- =========================================
-- STEP 5: CREATE INDEX
-- =========================================

CREATE INDEX idx_student_name
ON student(Name);

-- =========================================
-- STEP 6: VIEW INDEX
-- =========================================

SHOW INDEX FROM student;

-- =========================================
-- STEP 7: DROP INDEX
-- =========================================

DROP INDEX idx_student_name
ON student;

-- =========================================
-- STEP 8: VIEW INDEX AGAIN
-- =========================================

SHOW INDEX FROM student;

-- =========================================
-- STEP 9: CREATE VIEW
-- =========================================

CREATE VIEW student_view AS
SELECT Roll_No, Name, Course
FROM student;

-- =========================================
-- STEP 10: VIEW DATA THROUGH VIEW
-- =========================================

SELECT * FROM student_view;

-- =========================================
-- STEP 11: SHOW VIEWS
-- =========================================

SHOW FULL TABLES
WHERE TABLE_TYPE = 'VIEW';

-- =========================================
-- STEP 12: DROP VIEW
-- =========================================

DROP VIEW student_view;

-- =========================================
-- STEP 13: VERIFY VIEW IS REMOVED
-- =========================================

SHOW FULL TABLES
WHERE TABLE_TYPE = 'VIEW';

-- =========================================
-- STEP 14: ORIGINAL TABLE STILL EXISTS
-- =========================================

SELECT * FROM student;

-- =========================================
-- STEP 15: DROP TABLE
-- =========================================

DROP TABLE student;

-- =========================================
-- STEP 16: VERIFY TABLE IS REMOVED
-- =========================================

SHOW TABLES;

-- =========================================
-- STEP 17: DROP DATABASE
-- =========================================

DROP DATABASE drop_complete_db;
```
