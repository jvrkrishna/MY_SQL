# MySQL Data Types

In MySQL, data types are generally classified into three main categories:

1. String Data Types
2. Numeric Data Types
3. Date and Time Data Types

---

# 1. String Data Types

String data types are used to store **text, characters, and binary data**.

> **Note:** MySQL does not have a data type called `STRING`. Instead, it provides different data types such as `CHAR`, `VARCHAR`, `TEXT`, and `BLOB`.

## Common String Data Types

| Data Type | Description |
|---|---|
| `CHAR` | Fixed-length character string |
| `VARCHAR` | Variable-length character string |
| `TEXT` | Large text values |
| `BINARY` | Fixed-length binary string |
| `BLOB` | Binary Large Object |
| `ENUM` | One value from a predefined list |
| `SET` | One or more values from a predefined list |

---

## CHAR

`CHAR` is used to store **fixed-length character strings**.

### Features

- Stores alphabets, numbers, and symbols.
- Size range: `0` to `255` characters.
- Default size: `1`.
- Suitable when the length of the data is fixed or nearly fixed.

### Example

```sql
Gender CHAR(1);
