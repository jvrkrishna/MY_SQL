# TRUNCATE Command in MySQL

The `TRUNCATE` command is a **DDL (Data Definition Language)** command.

It is used to **remove all rows from a table** while keeping the table structure.

After using `TRUNCATE`:

* All rows are removed.
* The table remains.
* The table structure remains.
* The column names remain.
* The table can be used again to insert new data.

---

# Syntax

```sql id="g9d8kr"
TRUNCATE TABLE table_name;
```

### Example

```sql id="ikp2ks"
TRUNCATE TABLE stud_info;
```

This removes all rows from the `stud_info` table but does not remove the table itself.

---

# TRUNCATE vs DROP vs DELETE

`TRUNCATE`, `DROP`, and `DELETE` are different commands.

| Command    | What it does                      | Table remains? | Removes rows? |
| ---------- | --------------------------------- | -------------- | ------------- |
| `DELETE`   | Removes selected rows or all rows | Yes            | Yes           |
| `TRUNCATE` | Removes all rows                  | Yes            | Yes           |
| `DROP`     | Removes the entire table          | No             | Yes           |

## DELETE

`DELETE` is used to remove rows from a table.

```sql id="e8d9u6"
DELETE FROM stud_info;
```

It can also remove specific rows using a `WHERE` condition:

```sql id="9w2zjr"
DELETE FROM stud_info
WHERE Roll = 1;
```

## TRUNCATE

`TRUNCATE` removes **all rows** from the table.

```sql id="h1b4xc"
TRUNCATE TABLE stud_info;
```

A `WHERE` condition cannot be used with `TRUNCATE`.

## DROP

`DROP TABLE` removes the **entire table**, including its structure and data.

```sql id="qyk5uc"
DROP TABLE stud_info;
```

---

# Important Difference

```text id="5s7x4j"
DELETE
   ↓
Removes rows
   ↓
Table remains

TRUNCATE
   ↓
Removes all rows
   ↓
Table remains

DROP
   ↓
Removes table
   ↓
Structure + data are removed
```

> **Note:** `TRUNCATE` is generally faster than deleting rows one by one with `DELETE` when the goal is to remove all rows. It should not be described as simply "faster than DROP," because `DROP` performs a different operation by removing the table itself.

# Practical Example

## Step 1: Show Databases

```sql id="wyif1r"
SHOW DATABASES;
```

## Step 2: Create Database

```sql id="p3l4yf"
CREATE DATABASE COLLEGE;
```

## Step 3: Select Database

```sql id="2x30gm"
USE COLLEGE;
```

## Step 4: Create Table

```sql id="c1g2gf"
CREATE TABLE stud_info (
    Roll INT,
    Name VARCHAR(30),
    Course VARCHAR(20)
);
```

## Step 5: View Table Data

```sql id="db6eq5"
SELECT * FROM stud_info;
```

Since no records have been inserted yet, the table will be empty.

---

# Step 6: Insert Data

```sql id="0c7w6j"
INSERT INTO stud_info
VALUES (1, 'Raj_sekhar', 'MYSQL');

INSERT INTO stud_info
VALUES (2, 'Dinesh', 'Python');
```

> **Note:** The second student's `Roll` value is `2` so that each student has a different roll number.

---

# Step 7: View the Data

```sql id="iwm52p"
SELECT * FROM stud_info;
```

Example result:

| Roll | Name       | Course |
| ---: | ---------- | ------ |
|    1 | Raj_sekhar | MYSQL  |
|    2 | Dinesh     | Python |

---

# Step 8: TRUNCATE the Table

```sql id="4l6h20"
TRUNCATE TABLE stud_info;
```

All rows are now removed from the table.

---

# Step 9: View the Data Again

```sql id="4ezq48"
SELECT * FROM stud_info;
```

The result will contain **no rows**, but the table still exists.

We can verify the table structure using:

```sql id="i4c8y6"
DESC stud_info;
```

The columns `Roll`, `Name`, and `Course` will still exist.

---

# Complete Practical Example

```sql id="m2j1tm"
-- Show databases
SHOW DATABASES;

-- Create database
CREATE DATABASE COLLEGE;

-- Select database
USE COLLEGE;

-- Create table
CREATE TABLE stud_info (
    Roll INT,
    Name VARCHAR(30),
    Course VARCHAR(20)
);

-- View empty table
SELECT * FROM stud_info;

-- Insert records
INSERT INTO stud_info
VALUES (1, 'Raj_sekhar', 'MYSQL');

INSERT INTO stud_info
VALUES (2, 'Dinesh', 'Python');

-- View records
SELECT * FROM stud_info;

-- Remove all rows
TRUNCATE TABLE stud_info;

-- View table after TRUNCATE
SELECT * FROM stud_info;

-- Check whether the table structure still exists
DESC stud_info;
```
